# HollowConnect

和朋友一起探索圣巢、挑战 Boss，在倒地时互相救援。

HollowConnect 是面向《空洞骑士》一代的协作联机模组，提供怪物与 Boss 同步、可选的进度共享、队友定位和暗影救援，并附带 Windows 一键安装器。

**当前版本：0.2.4** · 支持 Windows 10 / 11 · 适配游戏版本 **1.5.78.11833**

0.2.4 修复联网 Boss 的死亡存档与重入复活、关闭进度共享时毛里克无法领奖的问题，并调整共享血量的面具 HUD、休息提示和配置布局。详见[更新日志](docs/UPDATE-0.2.4.md)。

## 可以一起做什么

| 功能 | 游玩体验 |
|---|---|
| 协作战斗 | 和队友一起迎战怪物与 Boss，也可结伴挑战神居。 |
| 共享进度 | 可共享移动能力、法术、护符及指定资源，分头探索也能一起成长。房主也可关闭共享，各自推进世界与剧情。 |
| 暗影救援 | 队友倒地后，用骨钉击破救援暗影，帮他恢复一格血；救人者获得 33 点灵魂。 |
| 队友定位 | 在地图上查看队友位置，通过屏幕边缘提示找到同房队友，查看跨房间队友所在的房间。 |
| 自选挑战规则 | 房主可调整救援次数、动态 Boss 血量、索敌模式，并开启 Boss 伤害占比榜。 |
| 队友互动 | 用梦之钉命中队友补充灵魂，使用快捷键传送到队友身边，按住 F5 查看死亡排行榜。 |

## 安装与开房

**游玩请使用 [HollowConnect-0.2.4-windows.zip](https://github.com/gengsha/HollowConnect/releases/download/v0.2.4/HollowConnect-0.2.4-windows.zip) 完整安装包。** GitHub 的 “Code → Download ZIP” 提供的是源码。

1. 关闭游戏，把安装包完整解压。
2. 双击 **一键安装.exe**，选择游戏后点击 **安装 / 更新**。安装器会自动查找 Steam 游戏库；也可点击 **选择游戏…**，手动找到 `hollow_knight.exe`。
3. 启动游戏，房主在 **选项 → 模组 → HollowConnect** 中设置本次联机规则。
4. 房主从 HKMP 的 **Multiplayer → Host** 开房，选择存档和 UDP 端口，例如 `26950`。
5. 队友选择 **Connect**，填写房主地址和对应端口，选择自己的存档，再选择 **确认加入**。

所有玩家须使用**同一版本的完整包**，更新后重新开房。本包已包含修改后的 HKMP 引擎和所需依赖，直接使用包内版本即可。

安装器会备份原游戏文件、已有 HKMP 和存档。请保留解压后的配套文件；安装无需 .NET SDK 或命令行操作。

## 房主设置

在 **选项 → 模组 → HollowConnect** 中调整。房主规则在开房时确定，修改后重新开房生效；队友透明度、名字配色等本机显示设置可随时调整。

| 选项 | 默认值 | 说明 |
|---|---|---|
| 共享永久进度 | 开启 | 共享指定能力、资源和永久进度；关闭后各自探索，保留匹配的同房 Boss 合作及队友位置。 |
| 共享护符 | 开启 | 在共享永久进度开启时，共享护符获得状态，装备搭配各自决定。 |
| 暗影救援 | 开启 | 队友用骨钉击破暗影即可救起。救援次数默认不限，可设置为每人 1／2／3／5／10 次，坐椅子恢复次数。 |
| Boss击败后解除暗影 | 开启 | 本场 Boss 被击败后，在存活参战队友处复活本场暗影玩家，不消耗救援次数。 |
| 入场免伤 | 开启 | 进入房间并恢复操作后，提供 1.5 秒反应时间。 |
| 动态 Boss 血量 | 关闭 | 根据同房人数增加 Boss 等效血量，适合希望提高挑战的队伍。 |
| Boss 增血参数 | 60% | 开启动态血量后生效；可输入 0–400。例如 80 时，两人 180%、三人 244%。 |
| Boss 索敌模式 | 原版 | 可选“灵活”，让 Boss 在合适时机切换目标。 |
| Boss 伤害占比榜 | 关闭 | 普通 Boss 按单场统计，神居一至五门按整门累计。 |
| 救援耗尽后观战（Beta） | 关闭 | 可在 Boss 战中跟随存活队友观战，也可提前返回自己的复活点。 |
| 共享血量 | 关闭 | 位于配置底部的独立分组，需同时开启进度和护符共享。全房间共用普通生命，蓝血各自独立；暗影救援和观战无效。[玩法说明](docs/LINKED-HEALTH.md) |
| 　额外面具 | 2 | 属于共享血量模式，可设为 0–10 格临时普通生命，与永久面具碎片进度分开。 |

共享范围包括移动能力、法术等级、护符、地图购买状态、护符槽、面具与容器碎片、苍白矿石、幼虫和梦境 Boss 首次精华奖励。简单钥匙与四种特殊钥匙（含城市纹章）按来源共享、各自消费；接收共享资源时有左下角提示。**吉欧、梦之树及其他零散精华、骨钉升级、装备和地图探索各自独立**。完整名单见[共享进度说明](docs/SHARED-PROGRESS.md)。

共享会写入所选存档，关闭后已获得的进度会保留。使用已有存档联机前，建议先备份。钢魂存档保留原版死亡规则，不应用暗影救援。

## 常用按键

| 按键 | 操作 |
|---|---|
| **F1** | 显示／隐藏 Boss 伤害占比榜，需房主先开启该功能。 |
| **按住 F5** | 查看死亡排行榜。 |
| **F6** | 放弃等待救援：开启观战时转为观战，否则按原版返回复活点；观战中再次按下可提前返回。 |
| **F7** | 循环选择队友，用于传送或观战。 |
| **F8** | 传送到所选队友，需房主允许传送。 |
| **F9** | 打开诊断面板，可导出诊断信息用于反馈。 |
| **Ctrl + Alt + F12** | 紧急回椅：断开本机联机，返回德特茅斯长椅并自动保存，不扣吉欧。 |

紧急回椅需先载入存档，并能正常接收按键。部分按键可在游戏关闭后通过 `%USERPROFILE%\AppData\LocalLow\Team Cherry\Hollow Knight\CoopMod.GlobalSettings.json` 调整。

## 远程联机怎么连接

HollowConnect 使用**一个 UDP 端口**，房主与队友按自己的网络条件选择：

- **同一局域网**：填写房主的局域网 IP 和开房端口。
- **ZeroTier / Tailscale 等虚拟局域网**：加入同一虚拟网络，填写房主在该网络中的 IP 和开房端口。
- **公网端口映射或 FRP**：将公网 UDP 端口转发到房主的开房端口，队友填写公网地址和映射后的端口。[FRP 配置示例](docs/frpc.example.toml)
- [用樱花内透网联机示例](https://www.bilibili.com/video/BV1pRn36oEGB/?buvid=XX649BA63488E83DC4FE64A800695885D6CEC&is_story_h5=false&mid=DqgU2LpeiSC2Uo0%2Btgw82g%3D%3D&plat_id=240&share_from=ugc&share_medium=android&share_plat=android&share_source=QQ&share_tag=s_i&spmid=dt.space-dt.0.0&timestamp=1793097243&unique_k=maFZjhZ&up_id=501517129)

请确保防火墙允许游戏和所用 UDP 端口，内网穿透服务支持 **UDP 转发**。房主在游戏内开房即可。

## 更新、卸载与反馈

**更新**：关闭游戏，解压新版本完整包，在安装器中点击 **安装 / 更新**。所有队友一起更新，再重新开房。

**卸载**：在安装器中选择游戏，点击 **卸载并恢复**。安装器会恢复最初安装前的游戏文件，保留当前存档；备份位于游戏目录的 `.HollowConnectBackups`。

安装时遇到写入权限不足，可右键安装器选择“以管理员身份运行”。安装日志位于 `%LOCALAPPDATA%\HollowConnect\Installer`。

遇到问题或有功能建议，欢迎提交 [Issue](https://github.com/gengsha/HollowConnect/issues)。反馈时附上模组版本、人数、所在场景、复现步骤和 F9 导出的诊断信息，方便定位。版本变更见[更新日志](docs/UPDATE-0.2.4.md)。
