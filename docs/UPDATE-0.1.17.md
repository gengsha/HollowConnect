# HollowConnect 0.1.17

本版合并 0.1.16 之后已完成的修复，使用普通小版本文件名 `HollowConnect-0.1.17-windows.zip`。

- 跨房 F8 传送选择实际有支撑的落点，改善苍绿酸水上窄平台的到达位置；保留原生危险地形复位，复位期间拒绝传送。
- 全队死亡或个人返回时，保留原生长椅起身和梦境唤醒的控制权，修复复活后只能移动、打开物品栏再关闭后失控的问题。
- 普通战士之梦由一人发起时，同房队友同步参与挑战和击败结算，各自领取原生精华奖励；不启动第二套原生 Boss AI。
- 房间初始快照和接管快照复用现有新旧字段过滤，防止迟到的旧状态覆盖较新的实体显隐、碰撞、位置和 FSM 状态。
- 保留 0.1.16 的剧情平台、水晶翻转平台本地运行、战斗同步性能和字符串遗漏修复。

安装前双方关闭游戏，完整解压新包，运行 **一键安装.exe → 安装 / 更新**，然后重新启动游戏、重新开房。模组版本应显示 **0.1.17**；房主与队友都要安装同一个完整包。FRP 端口设置沿用原配置。

本版构建的实际检查、专项范围与 DLL 哈希见 [0.1.17 运行记录](evidence/runtime-room-0.1.17.json)。此前修复过程分别见 [传送与输入](WARP-RESPAWN-INPUT-2026-10-15.md)、[战士之梦](DREAM-WARRIORS-2026-10-15.md)和 [快照顺序](SCENE-SNAPSHOT-ORDER-2026-10-15.md)；这些旧构建专项不自动计作本版验收。
