# HollowConnect 0.1.24（2026-10-18）

本版修复 0.1.23 仍存在的平台消失问题。菜单版本为 **0.1.24**，HKMP 引擎标识仍为 **3.0.0-hc11**，使用测试渠道。

## 原因与修复

Unity 仍会向禁用的 PlayMakerFSM 发送“变为可见”等消息。此前副本禁用了状态机组件，却继续接收这些消息；平台第一次被镜头看到时，PlayMaker 重新执行 Init，关闭显示和碰撞。网络上的平台组和快照仍显示正常，且权威没有状态变化，因此不会再发一次相同更新。这同时解释了平台实体统计一致、实际游戏却缺平台，以及纯批处理专项漏报的问题。

本版拒绝禁用的网络副本运行原生事件或进入原生状态，保留已启用的本机结算流程。修复适用于同类网络副本；本地镜头、挡板和挑战控制器按原流程运行。

## 安装

关闭游戏，完整解压 `HollowConnect-0.1.24-windows.zip`，运行 **一键安装.exe**，选择实际游戏目录并点击 **安装 / 更新**。房主与所有队友均更新到 0.1.24，重新开房并重新进入挑战。

紧急回椅 **Ctrl+Alt+F12**、诊断面板 **F9**、共享资源来源记录等既有功能继续保留。

## 验证方法

先在 0.1.23 上保留失败对照：普通辐光宣战前迟入，镜头渲染触发三个平台由可见可站立变为全部关闭；无上辐光二阶段渲染后也出现双方平台差异。原有六组专项未渲染、未覆盖宣战前，不能视为这两项问题已通过。

0.1.24 使用实际 Unity Player、D3D 游戏镜头和本机 UDP。普通辐光宣战前覆盖 F8／原生入口与两种先入顺序；二阶段覆盖雕像无上辐光、五门无上辐光、普通辐光及两种迟入方式。固定期望为初始挑战三座、普通辐光二阶段八座、无上辐光二阶段七座，以及各自十五／十八级爬升台阶。逐个平台检查渲染后显示、碰撞、真实重力支撑、镜头和控制，保留每端日志及镜头截图。
