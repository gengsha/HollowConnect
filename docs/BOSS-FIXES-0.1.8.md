# 0.1.8 Boss 试玩问题修复与复测

版本：HollowConnect 0.1.8 / HKMP 3.0.0-hc5，所有玩家同时更新。安装器继续自动查找 Steam 库并支持手选任意游戏目录；樱花 FRP 的 UDP 配置沿用。

本轮主要修复通用生成、战斗子树、原生碰撞和生命周期机制。表中的“处理”是实现对应关系；自动化观察不等于整场战斗、全部招式或真实公网验收。实际证据与范围见 [验证记录](VERIFICATION.md)。

| 大黄蜂飞针不可见且无伤害 | Needle 明确注册；捕获脱离父物的原生生成；补齐首个渲染/伤害值；保留副本碰撞刚体。 | 一代/二代大黄蜂的飞针来回都可见，两人分别触碰有伤害。 |

| 连接初期可能遗漏队友消息 | ServerInfo 先排队游戏初始化，再发布连接状态；普通玩家消息的处理器在主线程执行时查找，旧会话回调仍丢弃。 | 菜单连接、新档加入、退菜单重连与同端口重新开房均检查双方人物可见。 |

实战建议按一门到四门验证，并在每个异常 Boss 前后记录谁先进入房间。Boss 单体同步权威取先入房者，不一定是开服的房主，所以两种先入顺序都要覆盖。开启/关闭共享能力不会改变战斗权威。

出现异常时保留两端 ModLog.txt 与 Player.log，记录招式、房间、阶段和先入顺序。不要凭“客机画面看着正常”判断伤害和死亡已经同步，也不要把测试机器的批处理模拟帧率等同于实际显示帧率。
