# HollowConnect 0.2.3

2026-10-28。Windows 完整安装包与源码包，GitHub 正式 Release。网络标识 `0.2.3-l11`，引擎为 `3.0.0-hc13`。所有玩家更新为同一完整包后重新开房。

## 链在一起

- 新增默认关闭的“链在一起血条”，必须同时开启共享永久进度和共享护符。房主存档决定初始普通血量和永久上限；晚加入者继承团队当前血量。
- 全房间共用普通血量，受伤与治疗按实际格数共享，支持深度聚集。蓝血各自独立，先扣受伤者自己的蓝血，剩余伤害才扣团队血量；1 格蓝血面对 2／4 伤时，团队分别扣 1／3 格。
- 额外普通面具默认 2 格，可设 0–10。它只在房间内生效，与永久面具碎片进度分开；不同来源的碎片累计满四片增加一格，同一来源不重复计数。
- 全员就位才允许椅子／温泉回血，可以分处不同地点，也允许混合。含椅子的组合回满，全员温泉则每秒恢复一格。显示就位进度、未就位名单及加载／响应状态，野兽巢穴陷阱椅子不计入。
- 禁用生命血之心、生命血核心、脆弱／坚固心脏、乔尼的祝福和蜂巢之血，同时拦截装备与效果，始终允许卸下；禁止开启神居生命绑定。
- 模式内暗影救援和观战失效；普通与钢魂存档按房主类型准入，保留各自原版死亡规则。房主换档须重建房间。
- 关闭、退出或未满足前置开关时移除模式专用限制。临时团队血量和额外容量不写入个人存档，正常获得的永久进度保留。

完整规则及存档隔离边界见[玩法说明](LINKED-HEALTH.md)。

## 皮肤动画兼容

- 修复联机动画观察钩子的帧数取模错误，以及动画回调切换短动画后的旧范围访问。
- 为 Custom Knight 替换钟道兽过场视频加入准备时序适配，避免原生视频与皮肤 URL 在同一次构造中重复准备。无 Custom Knight 时保留原生流程。
- 兼容修改全部位于本模组，不要求修改皮肤；安装包不包含皮肤、Custom Knight 或 Satchel。

使用反馈者提供的 Lost Kin 皮肤完成针对性验证。动画越界已用旧 DLL 确定复现并修复；反馈中的进程级闪退在本机尚未复现，视频适配不能视为已确证该闪退根因。见[调查与验证说明](SKIN-COMPATIBILITY.md)。

## 下载与安装

- `HollowConnect-0.2.3-windows.zip`：游玩用完整包，含一键安装器及依赖。
- `HollowConnect-0.2.3-source.zip`：对应源码。
- `SHA256SUMS-0.2.3.txt`：两份压缩包的 SHA-256 校验值。

关闭游戏，完整解压 Windows 包，运行 **一键安装.exe** 并选择安装／更新。全员使用同一完整包并重新开房。

## 验证记录

“链在一起”开发阶段完成 316 项核心检查、最终构建 17 项相关核心检查及 28 组双端（16 项直接专项、12 项房间矩阵）；皮肤修复阶段完成 6 项相关核心检查及 5 组双端，其中四组包含 48 次实际视频解码、到站和联机状态检查（24 次自定义、24 次原生）。各阶段保留原始生产哈希，见[开发验证汇总](evidence/development-validation-0.2.3.json)。这些阶段使用不同构建，结果不合并宣称为同一最终构建的完整回归。

此次升版执行生产／安装器构建和完整包／源码包校验，没有因版本号变更重新启动游戏。正式 Release 按用户明确要求发布，历史未解记录保留在[问题账本](evidence/runtime-blockers-0.2.3.json)；最终包哈希及范围见[本版交付记录](evidence/runtime-room-0.2.3.json)。
