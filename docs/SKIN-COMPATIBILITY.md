# 皮肤管理器

在游戏主菜单或暂停菜单打开 **模组 → HKMP → 客户端设置 → 皮肤管理器**。

1. 点击 **打开皮肤目录**，把每套皮肤解压为一个文件夹。以《死亡细胞》为例，解压后目录结构为 `HKMP/SkinPacks/死亡细胞/Knight.png`。
2. 回到游戏点 **重新扫描**。在 **本机皮肤** 一行点左右箭头，或选中该行后用方向键／手柄左右切换。首次使用是 **原版外观**，扫描到的皮肤按名称接在后面，首尾相连。切换立即生效并保存在本机，离线也能换装。读不出来的皮肤会被跳过，并显示提示。
3. 联机时双方在各自客户端安装同一套皮肤包，并保留相同的皮肤文件夹名称。可以各自选不同的皮肤。房间默认开启皮肤分享。**查看队友皮肤** 默认为开启，本机装有队友正在用的皮肤包时才能看到这套皮肤。关闭开关后，本机看到的队友使用原版外观，队友仍按各自的设置看你的皮肤。

皮肤分享使用稳定的皮肤标识。普通皮肤用文件夹名，旧版皮肤带 `HKMP/Skins/` 前缀。接收端按标识从本机读取图集。找不到同名皮肤或图集读取失败时，对应部位显示原版。装好缺少的皮肤后点 **重新扫描**，可立即更新同场景队友的外观。已载入的 PNG 替换成新版后，重启游戏可刷新这些图集。房主关闭分享时，本机仍能换装，联机队友显示原版，重新开启分享会同步各自当前的选择。

## 旧皮肤和 Custom Knight

- `Mods/HKMP/Skins/` 的已有皮肤直接显示在列表里，带「旧版皮肤」标记。新版按目录名称识别这些皮肤。接收旧版编号时，只有本机存在唯一对应的 `id.txt` 才会使用它。目录和编号文件可留在原处。
- `Mods/CustomKnight/Skins/` 的 PNG 皮肤也会出现在列表里。启用兼容版本的 Custom Knight 时，它负责应用能够识别的皮肤及其扩展内容。Custom Knight 自己的换装也会反映在管理器里。
- 内置入口支持 `Knight.png`、`Sprint.png`、`Hud.png`、`Wraiths.png`、`VoidSpells.png`，对应角色、冲刺、血量 HUD、嚎叫和黑吼。视频、场景替换、护符、背包和皮肤自带脚本由 Custom Knight 的相关功能处理。Public Beta 可以直接使用《死亡细胞》等兼容 PNG 包。
