# 同步资源使用原版左下角提示（2026-10-20）

此前矿石只有左下角自绘文字，护符槽和两类碎片的文字则漂浮在人物旁，尚未复用原版物品提示。本次补齐同步接收方的展示。

## 实现

- `ResourceNotifications` 只接收已经成功提交的资源补发/补差回调。原版 `Relic Get Msg` 提示框、图标、字体和淡入淡出 FSM 用于左下角展示；名称从原版 UI 语言表读取。
- 从 Tutorial 胸箱的通用拾取 FSM 提取通知模板及矿石/护符槽图标，从 Sly 商店库存提取面具/容器碎片图标与名称。预加载对象全程不启用，提取后销毁；只保留禁用的通知模板与图标引用，不创建或缓存碎片收集 UI。
- 同一待显示类型累加数量，例如 `面具碎片 ×16`；四类提示依次播放，不覆盖、不丢弃满档补发中的其他类型。数值依旧在安全更新中直接结算，不等待 UI。后续单个碎片也显示原版图标和名称。
- 远端碎片仍直接增加上限或保留余数，不触发 `Heart Piece Instant`、`Vessel Fragment Instant`、`Heart Container UI`、`Vessel Fragment UI`。本地原生拾取流程保持原样。
- 取消旧的人物漂浮/矿石 GUI 提示及重复的顶部资源提示。暂停、过场或不能操作时不启动下一条；断线、切换存档及运行时销毁会清理本次提示。
- 来源并集、去重、个人骨钉和矿石消费规则沿用已有资源服务。

源码版本仍为 0.1.27，本次未打包或安装。当前哈希及完整测试记录见[机器可读证据](evidence/resource-notifications-2026-10-20.json)；此前直接结算记录保留原有受测哈希。
