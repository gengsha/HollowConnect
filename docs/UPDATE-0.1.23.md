# HollowConnect 0.1.23（2026-10-18）

菜单版本为 HollowConnect **0.1.23**，HKMP 引擎标识为 **3.0.0-hc11**。本包为测试渠道完整包。

## 修复内容

- 辐光战斗同步二阶段平台组、爬升台阶组和镜头阶段，迟入者接收当前状态。
- 雕像无上辐光、五门无上辐光和真结局普通辐光均支持 F8 传送迟入与正常入口迟入，已开战时结束过期的本机标题、白幕和入场锁定，恢复操作、HUD 与音乐。
- 正常入场完成后恢复已收到的有效危险复位点，防止原版入场流程将其覆盖到初始地面、导致二阶段反复落入深渊。之后仍可正常使用本机爬升复位点。
- 镜头按本机角色位置落位，阻止逃跑的挡板继续由本机触发。

紧急回椅 **Ctrl+Alt+F12**、诊断面板 **F9**、房主共享来源记录、资源去重与领取反馈等既有功能随包保留。

## 安装

关闭游戏，完整解压 `HollowConnect-0.1.23-windows.zip`，运行 **一键安装.exe**，选择实际游戏目录并点击 **安装 / 更新**。房主和所有队友使用同一个 0.1.23 完整包，更新后重新开房并重新进入挑战。

## 验证范围

升版本前的最终修复构建通过六组本机双 Unity Player 专项：雕像、五门、剧情辐光各覆盖 F8 与正常入口；包含双方先入顺序、完整平台组、爬升台阶、镜头、真实重力支撑与原生危险复位点，其中一组覆盖实际丢包、乱序、重复网络故障。30 项相关核心回归通过。

0.1.23 在这批验证后仅修改模组版本常量，并更新交付脚本及文档；重新编译并校验安装包。没有对升版本后变化的 DLL 哈希重跑 Unity 专项。原始测试证据及其 DLL 哈希保留，不能将它们解释为新哈希的实机验收。

没有完成最终击杀与结局、完整五门流程、双机 FRP 或全部 Boss 验收。历史未解项目继续保留，本次打包不将它们标为解决。
