# HollowConnect 0.3.2-rc1

本候选版修复队友先触发遭遇战时门已关闭、敌人却无法正常入场的问题。

- 苍绿之境 Fungus1_32 的苔藓骑士会响应入场者的原版唤醒信号，即使负责运行敌人的玩家仍在门外。
- 王后花园 Fungus3_05 和 Fungus3_10 会开始原版波次。每位玩家的门仍由本地入场触发，敌人击败后按原版流程开门。

下载与你的游戏版本匹配的 Windows 安装包。Legacy 对应 1.5.78.11833，Unity6 对应 1.5.12620。联机的玩家请都安装 0.3.2-rc1。

本候选版在两个游戏版本分别做了三间房的双端联机验证，并通过 13 项相关核心检查。
