# HollowConnect 0.1.28 更新日志

2026-10-20，测试渠道。包含资源补发、同步提示、碎片重复领取收尾，以及五门行程上下文修复。**所有玩家须使用同一个 `HollowConnect-0.1.28-windows.zip` 完整包，更新后重新开房、重新进入挑战。** 引擎标识为 `3.0.0-hc12`，附加网络标识为 `0.1.28-l1`。旧 0.1.27 安装包和失败证据保留。

## 修复及资源规则

- **新档进满能力档，槽位／矿石没有到账。** 无普通领取标记的神居满档只有能力数值，旧版无法导入资源来源。本版在安全入档／入队核对时，恢复可证明完整领取的来源：11 槽对应全部 8 个槽来源、16 面具碎片总量对应全部面具来源、9 容器碎片总量对应全部容器来源；现有矿石加个人骨钉历史耗矿恰好为 6 时恢复全部矿石来源。部分数值不能唯一确定来源时不编造记录，也不按 112% 字样推算。
- **同步的面具／容器碎片直接结算。** 每 4 个面具碎片增加一格生命上限，每 3 个容器碎片增加 33 额外灵魂容量，余数保留。入房补差及远端新增资源不启动碎片收集／合成动画，不夺取角色控制；资源到账使用原版左下角 `Relic Get Msg` 提示、原版图标和本机语言名称，多种资源依次显示，重复来源不重复提示。本地首次拾取和购买保留原版动画。
- **修复同步后本地再买同一碎片卡在收集界面。** 去重后若碎片余数已归零，原版计数展示没有 0 分支，会留下禁止操作／暂停的状态。现在重复领取在原版初始化完成后正式切换到收尾状态，由原版结束动画和销毁流程恢复操作、暂停、重力与无敌标记。面具与容器 UI 一并处理；已共享后确认的重复购买不重复扣费、不重复发资源。
- **五门换房不再恢复成旧行程。** 正常载入提交上下文；场景／索引不匹配时不广播空行程；拒绝同房空行程清掉有效五门；补齐当前控制器缺失的原生完成回调；保留温泉／乌恩出口的原生推进，避免重复推进；结算后拒绝迟到心跳和重复完成。没有硬编码“六喜丸子打完强制跳乌姆”。

世界资源继续按**来源并集**共享，每个存档每个来源只结算一次。**骨钉等级、伤害及强化扣费各自独立，已经消费的矿石重连不返还。** 吉欧、精华、装备及个人存档字段继续按既有规则处理。共享永久进度默认开启，已有配置保存的关闭仍保留；动态 Boss 血量默认关闭。

若双方在来源消息到达前同时确认购买，仍可能各自按原价付费；本版没有预约或退款机制。上述免费重复确认指本机已经收到该来源后的购买，不能延伸为所有并发购买都只付一次钱。

详见[满档资源补发](RESOURCE-CATCHUP-2026-10-20.md)、[远端直接结算](DIRECT-RESOURCE-SETTLEMENT-2026-10-20.md)、[原版资源提示](RESOURCE-NOTIFICATIONS-2026-10-20.md)、[碎片界面修复](SHOP-SHARD-STALL-FIX-2026-10-20.md)和[五门修复](P5-WATCHERS-FIX-2026-10-20.md)。这些历史报告保留各自当时的版本、哈希和“未打包”状态；本次交付以本日志及新版验证记录为准。

## 安装

关闭游戏，完整解压 Windows ZIP，运行 **一键安装.exe → 安装 / 更新**。房主和全部队友一起更新并重新开房、重新进入挑战；旧会话已经分叉的状态不能原地恢复。保留安装器旁的 `payload`、`dependencies` 与脚本。诊断 **F9**、紧急回椅 **Ctrl+Alt+F12** 沿用既有功能，操作细节见 [README](../README.md)。
