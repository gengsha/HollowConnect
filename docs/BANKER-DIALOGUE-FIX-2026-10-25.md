# 银行家藏匿地交谈卡死修复

2026-10-25，HollowConnect 0.1.37 / HKMP 3.0.0-hc13，网络标识 `0.1.37-l8`。

## 原因与范围

在欢乐之屋温泉 `Ruins_Bathhouse`，银行家本体 `Banker Spa NPC` 的 `tink_effect` 收到攻击的 `TAKE DAMAGE` 后，发送方向性受击事件到 `Hit Around`。其原生 `Cancel NPC` 会停用子对象 `NPC`，随后缩壳、掉钱。本机交谈期间无法自行挥刀，但另一玩家的骨钉仍能走到这个受击流程。交谈对象失活后，原生对话界面找不到仍在运行的结束接收者，角色输入和 `disablePause` 没有正常收尾。

修复前的真实双端复现见 `.test-results/banker-before-20261025`：房主通过交谈范围和向上输入进入 `Meet`，访客实际挥刀；房主记录 `Cancel NPC → Withdraw → Give Geo`，交谈对象失活。原始失败证据保留。

新增 `BankerDialogue`，在已有 `EntityHooks.ProcessEvent` 接收处，仅当接收对象名称、场景均准确匹配该银行家，并且原生 `NPC/npc_control` 的 `Talking` 为真时，忽略 `TAKE DAMAGE`。保护从原生取得对话控制起，到原生 `Convo End` 清除 `Talking` 为止；其它时间继续走原生受击。

这是该银行家本机交谈期间的短暂受击保护，覆盖此时到达的攻击。没有新增网络消息，没有注册或同步银行家实体，没有更改通用 NPC、Boss、格林、金钱共享、原生对话动作或其它对象的事件规则。没有每帧强制解锁、强置 UI 状态或销毁对话界面。梦之钉读心等其它交互路线不在本次验收范围内。

## 最终验证

使用已有隔离游戏副本，通过真实 UDP 连接；内存中设置已发生银行家盗款及余额，不写个人存档。进入原生房间后，将角色摆到银行家旁，实际触发原生交谈范围和向上输入；另一端调用原生角色挥刀，远端复制刀光实际与银行家碰撞。

| 最终运行 | 交谈者 | 验证结果 |
| --- | --- | --- |
| `banker-final-host-20261025` | 房主 | 双端通过，严格日志通过 |
| `banker-final-guest-20261025` | 访客 | 双端通过，严格日志通过 |

每组均验证首次 `Meet` 及再次 `Repeat`：远端刀光命中来源有标记，对话接收者保持激活且没有缩壳掉钱；使用真实跳跃键翻页到原生结束，`Conversation Control` 回到 `Idle`，`Talking` 清除，输入和暂停恢复。攻击者自己的银行家未在交谈，仍能受击并掉钱；交谈者结束后也实际挥刀，通过原生 `Give Geo` 减少余额并生成真实吉欧。

最终生产 DLL 在升版后构建并保持冻结，两组测试及打包均核对三个生产 DLL 的 SHA-256。没有另加与 Unity FSM 无关的核心用例。测试夹具启动失败、修复前产品复现和编译失败均单独保留；最终通过记录没有覆盖这些失败。原生静态依赖审计沿用相同游戏程序集的既有记录，并增加本次银行家 FSM 运行时检查。

完整最终哈希、测试插件哈希、依赖、参数、失败分类见[银行家证据](evidence/banker-dialogue-fix-2026-10-25.json)。范围内六份既有生产源码的哈希核对通过，包括飞虫召唤、清场、斗兽场入口、救援及资源共享相关文件。
