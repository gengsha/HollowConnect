# HollowConnect 0.2.7

2026-11-03。Windows 完整安装包包含匹配的 HKMP、Steam 好友联机预览模块和依赖。所有玩家更新同一完整包后重新开房；显示版本为 `0.2.7`，网络标识为 `0.2.7-l14`，HKMP 引擎仍为 `3.0.0-hc13`。

## 联机入口与修复

- 主菜单提供独立的「局域网联机」和「Steam 联机」。两页使用空洞骑士原生菜单、按钮、光标、音效、字体及导航；选档取消后返回发起的联机页。
- Steam 可创建好友房间、打开好友邀请、接受邀请或加入好友主持的游戏；游戏内 F10 打开原生房间菜单，返回暂停页后可继续游戏。Steam 通道经本机 UDP 桥接进入原有 HKMP，伤害、Boss、救援、存档与房间逻辑共用，局域网、IP／域名直连和内网穿透继续可用。
- 修复竞技场进场大包在丢包后反复积累重发、堵塞后续同步的问题。完整状态合并过期副本，大包压缩分片，重发分批发送，迟到确认可撤销排队重发；避免小心跳确认在大包尚未组装完时过早触发重发。
- 统一补齐根动画与托管显示子物体的可恢复状态：播放实例、进度、停止帧、启用状态、颜色和局部变换。丢失一次切换后可由后续状态恢复，改善竞技场地刺贴图未收回、神之驯服者野兽翻滚和席奥动作丢失。Steam 与 IP 方式共用该同步路径；客机不执行复制动画的攻击／生成物体回调。
- 修复巨型斩、冲刺斩在特定受击动画及共享血量多个碰撞体下重复命中特效、喷血。保留旋风斩原生多段命中；异常旋风斩喷血尚未独立复现。
- 救援复活后使用与原生受伤相同的无敌时间，包括坚硬外壳的延长效果。修复退出游戏后的零线程残留记录导致安装器误判游戏仍在运行。

## 安装

下载并完整解压 [HollowConnect-0.2.7-windows.zip](https://github.com/gengsha/HollowConnect/releases/download/v0.2.7/HollowConnect-0.2.7-windows.zip)，关闭游戏后运行 **一键安装.exe**。`HollowConnect-0.2.7-source.zip` 为对应源码，不能直接作为安装包。Steam 使用方法见 [联机说明](STEAM-MULTIPLAYER.md)。

## 验证与保留问题

升版前的统一显示修复构建通过 **102 项核心检查、20 组同机双端检查**，包含原生野兽／席奥、地刺、受限链路竞技场和 12 项房间矩阵。随后原生菜单构建通过 **9 项相关检查、4 组双端流程**，覆盖带／不带 Steam 模块的菜单、IP 加入／重连／重新开房，以及真实 SDK 回环、单账号大厅、游戏内菜单与清理。这两个阶段使用不同的生产哈希，详见 [开发验证摘要](evidence/development-validation-0.2.7.json)。

本次升版只改版本常量、程序集版本、连接兼容标识、文档及打包版本；执行构建、安装流程与包完整性核验，没有重跑游戏矩阵，不把旧结果追认为 0.2.7 新哈希的完整验收。交付哈希与范围见 [发布记录](evidence/runtime-room-0.2.7.json)。

大黄蜂掷针期间断线／控制权交接后可能停在 `Thrown`，仍未修复。真实双账号邀请、游戏关闭时接受邀请、跨机器 P2P／Steam 中继仍需玩家继续验证。模拟弱网通过不能证明玩家原现场所有 Steam 异常的根因；显示采样增加 CPU 开销，不保证普遍提升 FPS。竞技场只覆盖加速原生第 1–34 波，不等同于正常武器全程通关。其它历史报告与未覆盖项保留在 [已知问题](KNOWN-ISSUES.md) 和 [完整账本](evidence/runtime-blockers-0.2.7.json)。
