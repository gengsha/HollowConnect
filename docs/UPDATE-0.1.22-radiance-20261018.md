# 0.1.22 辐光修复测试包（2026-10-18）

交付标签：`0.1.22-playtest-radiance-20261018`。菜单版本仍为 HollowConnect 0.1.22 / HKMP 3.0.0-hc11；本包保留已通过实机专项的生产 DLL，不因打包重新编译或改版本号。

## 本次修复

- 镜头锁区按本机位置触发，避免队友入场影响本机镜头。
- 无上辐光二阶段使用有效平台与原生危险复位点，避免落入地下后连续扣血。
- 传送迟入已开战的无上辐光房间时，结束本机入场展示，恢复 HUD、音乐和镜头落位，避免稍后再次出现标题。不重置 Boss 血量与阶段。
- 为同类 HazardRespawn 触发补充 Boss 归属、编号范围、缺失对象与复位标记校验。

此前的紧急回椅、资源共享和本地挡板等改动随当前构建保留。紧急回椅为 **Ctrl+Alt+F12**，诊断面板为 **F9**。

## 安装

关闭游戏，完整解压 `HollowConnect-0.1.22-playtest-radiance-20261018-windows.zip`，运行 **一键安装.exe**，选择实际游戏目录并点击 **安装 / 更新**。房主与所有队友使用同一个带本次标签的完整包，更新后重新开房、重新进入挑战。旧构建也可能显示 0.1.22，请按压缩包标签核对。
