# 0.3.1

- 修复黑波（暗影之魂）获取地召唤阶段的随机动作目标解析异常：正确处理原生 `FsmOwnerDefault` 与 `FsmGameObject`，避免把目标选择器误作 Unity 对象，导致召唤流程抛出空引用。实际路线为典雅钥匙 → 灵魂圣所钥匙门 → `Ruins1_31b` 灵魂战士，覆盖两种先入顺序与队友触发。
- 同时保留水道粪虫防御者由另一玩家触发时的权威唤醒修订。水道测试与黑波路线分开记录。
- 新增英语、日语；模组菜单、连接菜单、Steam 房间与主要玩家提示跟随游戏语言切换。玩家名和输入内容保持原样。
- 安装器新增简体中文 / English / 日本語选择。
- 灵魂 HUD 附近的跨房名单、主动放弃等常驻或开发状态小字移入日志；地图队友定位和按键主动打开的榜单、F9 诊断保留。
- GitHub 首页与本次 Release 明确提供安装器、脚本、手动三种安装方式。

## 下载与安装

Windows 10/11：Legacy 对应 1.5.78.11833 / Unity 2020.2.2；Unity6 对应 1.5.12620 / Unity 6000.0.61f1。选择匹配游戏版本的完整 Windows ZIP。Unity6 自带固定社区 API（468f579），不能使用 Legacy v77。

## 验证范围与限制

本版只执行相关核心、菜单语言切换、安装器、黑波路线和水道直接回归；未重跑完整房间矩阵。最终构建和双端结果见 [验证记录](evidence/development-validation-0.3.1.json)，实际 FPS 见 [帧统计](PERFORMANCE-0.3.1.md)。帧统计来自同机两个隔离客户端，不代表所有设备表现；此前偶发 low 帧尚未归因，不宣称已修复。

既有未解决问题见 [已知问题](KNOWN-ISSUES.md)。Steam 真实双账号邀请和跨机器连接仍待实测；两种游戏版本分别验证，不承诺混合游戏版本房间。
