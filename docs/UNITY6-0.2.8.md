# HollowConnect 0.2.8 · Unity6 新版游戏包

适用于 Windows Hollow Knight **1.5.12620 / Unity 6000.0.61f1**（Steam public-beta）。包名包含 `unity6`；所有玩家使用同一游戏版本和同一完整包。游戏内模组版本仍为 0.2.8，网络标识仍为 0.2.8-l15。旧版 1.5.78.11833 使用原有安装包；新旧游戏混合房间未验证。

## 安装

1. 关闭游戏，完整解压 `HollowConnect-0.2.8-unity6-windows.zip`。
2. 双击“一键安装.exe”，选择新版游戏目录，点击“安装 / 更新”。不需要另找 Modding API。
3. 从 Steam 启动游戏，通过主菜单“局域网联机”主持或加入。Steam 好友模块已包含，也可使用主菜单“Steam 联机”或 F10；详细操作见包内 `docs/STEAM-MULTIPLAYER.md`。
4. 更新时全员关闭游戏、安装同一完整包，再重新开房。卸载使用“卸载并恢复”；当前存档不会回滚。

安装器精确校验原版／本包 API 的程序集哈希，先备份再写入。API、模组和安装器旁的文件必须完整保留。若游戏升级后仍指向旧游戏版本的卸载备份链，安装器会拒绝更新和恢复；先完整保留并另行归档该游戏的旧 `.HollowConnectBackups` 目录，再重新安装，以便为新版建立独立备份。不要将旧版游戏程序集恢复到新版引擎。

第三方模组也需要支持这个游戏/API 版本；本包的同步开发支持指同一源码分别构建两版。共享进度、血量和观战规则见包内对应指南。API 采用尚未合并的 [社区 PR #164](https://github.com/hk-modding/api/pull/164)，固定提交 `468f579f25e63da2188f39fe5ece15c25d2854d7`；配套依赖已包含。

## 验证与限制

新版最终 DLL 上，8 组直接专项与 12 项房间矩阵均双端通过，另有 70 项相关核心检查通过。包括原生入口、断线接管、Boss 阶段、Grimm、救援、死亡返回、重新加入、隔离加密存档往返、中文通知和 Steam 原生回环收发。记录见包内 `docs/evidence/development-validation-unity6-20261111.json`。

API／游戏底座在启动预加载时仍可能报告原生 `GameManager.SetupHeroRefs` 空引用；仅 API、空 Mods 对照也能复现，上述游戏流程可继续并完成。真实双账号 Steam 邀请、跨机器中继、全部 Boss 与完整三人流程尚未认证。既有 0.2.8 未解问题见包内 `docs/KNOWN-ISSUES.md`，本包未将历史问题标为已修复。

本包为用户请求的本地 Unity6 适配交付。包内常规 0.2.8 更新说明保留旧版发布历史，Unity6 验证范围以本说明及新版验证记录为准。
