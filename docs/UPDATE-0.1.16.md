# HollowConnect 0.1.16

本版合并 0.1.15 之后已完成的普通流程与公共性能修复，使用普通小版本文件名 `HollowConnect-0.1.16-windows.zip`。

- 梦之钉剧情中的浮升平台接受双方靠近状态，支持换房、迟入和权威接管。
- 水晶山峰翻转平台改为双方各自运行；根动画帧不再反复触发未使用的整套战斗快照。
- 较大的完整战斗状态独立压缩，减少编码临时数组并复用未发送采样缓冲；主线程积压按顺序分帧处理，预制体缺失时同帧复用资源候选。
- 修复 FSM 字符串初值为 null 后有效变化不发送，以及清空值无法发送的问题。
- 保留 0.1.15 的共享鹿角站即时刷新、个人地图/吉欧规则和此前复活重力修复。

安装前双方关闭游戏，完整解压新包，运行 **一键安装.exe → 安装 / 更新**，然后重新启动游戏、重新开房。模组版本应显示 **0.1.16**；房主与队友都要安装同一个完整包。FRP 端口设置沿用原配置。

本版交付 DLL 已通过 147 项回归、14 项严格日志检查、13 项安装器检查，以及五组同机隔离双客户端专项：两种先入顺序的激光/法师战斗（反向含丢包、重复、乱序）、水晶本地翻转平台与城内动画、剧情平台换房/接管，以及共享鹿角站提示内刷新和双方实际购买地图。双方正常完成并停机后复扫日志，安装包核对同一组 DLL 哈希。该范围不等于真实双机 FRP 或完整发布矩阵通过。

压缩前后的同配置同机观察中，激光房/法师房战斗状态载荷约减少 71%/64%；这属于旧候选构建的应用层对比，解压有 CPU 代价，不等于本版实际帧率提升。当前交付 DLL 的测试与哈希以 [0.1.16 运行记录](evidence/runtime-room-0.1.16.json) 为准，历史过程见 [公共性能专项](COMBAT-PERFORMANCE-2026-10-15.md)、[平台与城内专项](PLATFORM-CITY-PERFORMANCE-2026-10-15.md)、[剧情平台专项](DREAM-PLATFORMS-2026-10-15.md)和 [字符串专项](FSM-STRING-SYNC-2026-10-15.md)。

仍待定位：双方购买科尼法地图后持续互相不可见、Mines_11 的 FSM String 数组越界、旧断线接管飞针和假骑士样本、历史镜头冻结。位置平滑、大批副本创建和真实双机 FRP 改善仍需专项验证。本包按用户更新请求交付，保留已知问题和 `releaseReady=false`，没有把完整发布矩阵记为通过。

建议先复测梦之钉剧情平台、水晶翻转平台、泪水之城、激光虫和法师弹幕。若再出现互相不可见或异常，重开游戏前保留双方 ModLog.txt / Player.log。
