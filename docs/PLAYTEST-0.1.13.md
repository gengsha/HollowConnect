# 0.1.13 试玩包：dc0a4f5 构建

本包按用户在了解剩余问题后提出的“打包吧”提供。HollowConnect 为 0.1.13，HKMP 为 3.0.0-hc10；三个生产 DLL 使用 `dc0a4f5` 构建，打包时不重建。包含一键安装器，支持自动发现各盘 Steam 库或手选游戏目录。旧包保留，双方必须使用文件名带 `dc0a4f5` 的同一个完整包；菜单版本号相同不代表 DLL 相同。

本次包含后续公共 FSM、网络可靠性和同一数据报跨帧应用修复。143 项回归、14 项严格日志门槛，以及原周期正向/固定种子反向两组各八次接管和自然回收通过，详见[本次验证](DATAGRAM-FRAME-COMMIT-2026-10-14.md)和[打包请求及实际 DLL](evidence/playtest-authorization-0.1.13-dc0a4f5.json)。旧[12 组运行证据](evidence/runtime-room-0.1.13.json)属于 `6ddf5b3`，不能作为当前 DLL 的完整验收。

保留的实际失败：大黄蜂投针后接管可能停在等待回收状态；假骑士再次破甲曾未露头；历史入场镜头曾瞬时冻结。[未解决问题](evidence/runtime-blockers-0.1.13.json)保留三类记录。最新专项通过仍不能确定这些旧失败的唯一根因。另有[重筛报告](RESCREEN-REVIEW-2026-10-14.md)所述静态风险、全部 Boss 招式、完整神居连战、普通流程关键奖励、三四人和真实双机 FRP 尚未完整验收。本包仅供试玩，`releaseReady=false`。

## 安装与复测

1. 房主和全部队友先正常退出游戏，完整解压 `HollowConnect-0.1.13-playtest-dc0a4f5-windows.zip`，双击“一键安装.exe”，点击“安装 / 更新”。无需先卸载；游戏位置不同可以分别手选自己的目录。
2. 双方确认使用同一 `dc0a4f5` 完整包，重新开房并重新开始挑战。FRP 的 UDP 端口设置沿用原配置。
3. 一门先试房主先进、客机晚进，再反过来；尤其检查大黄蜂房间双方是否可见、是否在打同一个 Boss、击杀后是否都进入下一房，以及退菜单重连后的表现。
4. 再验证曾报告的弹幕、卡顿和救援问题；普通流程另外观察关键奖励是否正常。

发生问题时，记录双方当前房间、先入顺序、正在释放的招式、谁看不见谁，以及是否刚死亡、传送或重连。重开游戏前先保存双方 `%USERPROFILE%\AppData\LocalLow\Team Cherry\Hollow Knight\ModLog.txt`，避免后一次启动覆盖日志。日志可能含玩家名称或连接地址，可私下提供用于排查。

安装器保留最初备份和现有存档；需回退时用“卸载并恢复”。回退模组不会自动回退试玩产生的存档进度，重要存档可另保留一份。
