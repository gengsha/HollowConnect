本包沿用用户“打包吧”及后续继续修复的要求，提供复活浮空和灵魂暴君下砸重复查找的修复版。HollowConnect 为 0.1.13，HKMP 为 3.0.0-hc10；三个生产 DLL 使用 `1f5efe0` 构建，打包时不重建。包含一键安装器，支持自动发现各盘 Steam 库或手选游戏目录。旧 `dc0a4f5` 包保留，双方必须使用文件名带 `1f5efe0` 的同一个完整包；菜单版本号相同不代表 DLL 相同。

本次让原生流程恢复复活重力，减少大量尖刺生成时的重复资产/字段解析；保留已有公共 FSM、网络可靠性和同一数据报跨帧应用修复。当前 DLL 的 143 项回归、14 项严格日志检查和六组同机双客户端专项通过，覆盖普通全队死亡、神居/梦境个人返回、两种入场顺序及灵魂暴君二阶段实际下砸，详见[专项验证](RESPAWN-SOUL-SLAM-2026-10-14.md)和[打包请求及实际 DLL](evidence/playtest-authorization-0.1.13-1f5efe0.json)。批处理性能结果不能保证双机最终 FPS，权威端仍有长帧样本。旧网络专项和[12 组运行证据](evidence/runtime-room-0.1.13.json)保留各自的旧构建归属，不能作为当前 DLL 的完整验收。

保留的实际失败：大黄蜂投针后接管可能停在等待回收状态；假骑士再次破甲曾未露头；历史入场镜头曾瞬时冻结。[未解决问题](evidence/runtime-blockers-0.1.13.json)保留三类记录。最新专项通过仍不能确定这些旧失败的唯一根因。另有[重筛报告](RESCREEN-REVIEW-2026-10-14.md)所述静态风险、全部 Boss 招式、完整神居连战、普通流程关键奖励、三四人和真实双机 FRP 尚未完整验收。本包仅供试玩，`releaseReady=false`。

压缩包核验通过。本轮安装器流程复测前四项通过，其余被路径不可读的现有游戏进程拦截，未完整复测；没有停止这些进程或修改安装器代码。正常退出游戏后再安装。

## 安装与复测

1. 房主和全部队友先正常退出游戏，完整解压 `HollowConnect-0.1.13-playtest-1f5efe0-windows.zip`，双击“一键安装.exe”，点击“安装 / 更新”。无需先卸载；游戏位置不同可以分别手选自己的目录。
2. 双方确认使用同一 `1f5efe0` 完整包，重新开房并重新开始挑战。FRP 的 UDP 端口设置沿用原配置。
3. 优先在原故障房间双方全队死亡，返回各自复活点并正常按键醒来，连续跳两三次，检查能否自然下落与落地；普通长椅、神居、梦境分别观察。
4. 梦境灵魂暴君分别让房主先入、客机先入，观察一、二阶段下砸，记录哪一端掉帧。再复测原弹幕、救援、大黄蜂与假骑士接管、退菜单重连和关键奖励。

发生问题时，记录双方当前房间、先入顺序、正在释放的招式、谁看不见谁，以及是否刚死亡、传送或重连。重开游戏前先保存双方 `%USERPROFILE%\AppData\LocalLow\Team Cherry\Hollow Knight\ModLog.txt`，避免后一次启动覆盖日志。日志可能含玩家名称或连接地址，可私下提供用于排查。

安装器保留最初备份和现有存档；需回退时用“卸载并恢复”。回退模组不会自动回退试玩产生的存档进度，重要存档可另保留一份。
