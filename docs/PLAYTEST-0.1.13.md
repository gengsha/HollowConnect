# 0.1.13 试玩包

本包按用户“先打包，我们试玩查 bug”的要求提供。HollowConnect 为 0.1.13，HKMP 为 3.0.0-hc10；三个生产 DLL 使用已完成 12 组同机双客户端验证的 `6ddf5b3` 构建，打包时不重建。包含一键安装器，支持自动发现各盘 Steam 库或手选游戏目录。

仍有一次历史入场镜头冻结没有确认唯一原因；全部 Boss 招式、完整神居连战、普通流程关键奖励和真实双机 FRP 尚未完整验收。[运行证据](evidence/runtime-room-0.1.13.json)和[未解决问题](evidence/runtime-blockers-0.1.13.json)保留原状态。试玩包不表示这些问题已修复或完成正式验收。

## 安装与复测

1. 房主和全部队友先正常退出游戏，完整解压 `HollowConnect-0.1.13-playtest-windows.zip`，双击“一键安装.exe”，点击“安装 / 更新”。无需先卸载；游戏位置不同可以分别手选自己的目录。
2. 双方核对 HollowConnect 0.1.13 / HKMP 3.0.0-hc10，重新开房并重新开始挑战。FRP 的 UDP 端口设置沿用原配置。
3. 一门先试房主先进、客机晚进，再反过来；尤其检查大黄蜂房间双方是否可见、是否在打同一个 Boss、击杀后是否都进入下一房，以及退菜单重连后的表现。
4. 再验证曾报告的弹幕、卡顿和救援问题；普通流程另外观察关键奖励是否正常。

发生问题时，记录双方当前房间、先入顺序、正在释放的招式、谁看不见谁，以及是否刚死亡、传送或重连。重开游戏前先保存双方 `%USERPROFILE%\AppData\LocalLow\Team Cherry\Hollow Knight\ModLog.txt`，避免后一次启动覆盖日志。日志可能含玩家名称或连接地址，可私下提供用于排查。

安装器保留最初备份和现有存档；需回退时用“卸载并恢复”。回退模组不会自动回退试玩产生的存档进度，重要存档可另保留一份。
