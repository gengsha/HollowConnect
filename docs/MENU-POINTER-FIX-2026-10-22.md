# 模组菜单鼠标左右点击修复（2026-10-22）

`menu-left-right-fix.patch` 将原来仅用于皮肤选择器的修复扩展到所有 Modding API 自定义设置。原生点击逻辑只在命中左侧小箭头时递减，其余位置默认递增，因此点菜单行左半边也可能向后切换。本次采用行左右半边决定方向，同时把范围限定为 HollowConnect 和 HKMP 创建的菜单项。

`MenuPointerNavigation.Attach` 在两个模组自己的菜单构建完成后标记水平选项。鼠标钩子仅处理带标记的行，用事件相机转换坐标，再调用原生 `OnMove`，继续使用原来的循环、显示和保存回调；其他模组及原版菜单继续执行原生点击处理。标记不持有菜单集合，没有新增逐帧检查。

联机配置锁定仍然使用固定单值列表与受保护的保存回调。连接中、联机中及房主仍开房时，相关规则显示实际房间值和解锁提示；离线且停服后恢复编辑。本机显示选项仍可即时调整。
