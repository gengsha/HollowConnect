## 修复

- **藤蔓石块只响应本机骨钉。** 苍绿之径可砍断藤蔓、落下的石块不会再被队友的同步刀光砍落，避免把本地玩家压下平台。19 项石块掉落记录不再共享，旧同步记录也不能覆盖本地状态；自己的砍断、掉落和存档记录继续由原版处理。
- **关门精英战迟入后正常结算。** 修复队友已击杀敌人，自己随后进房或晚触发本地战斗时，敌人数被重新初始化、导致没有奖励且无法开门的一种时序。挡板继续走本地触发；保留本机死亡计数，补计早到的死亡记录，并防止重复计数和重复领奖。
- **HKMP 皮肤编号可以减少。** 修正鼠标点击左侧箭头后仍增加编号的问题，保留键盘选择。
- **清理离房后的 Boss 难度登记。** 房间卸载时清空旧目标登记，避免跨房残留。玩家骨钉和法术属性不被改写，普通怪按正常伤害结算。

## 新增设置与显示

- **队友透明度：** `OtherPlayerOpacity` 可调整本机看到的队友身体和特效，范围 `0`～`1`，默认 `1`；`0.5` 为半透明。
- **名字配色：** 队友名字与地图／屏外方位提示使用同一颜色，自己的名字仍为白色，方便辨认。
- **按人数调整 Boss 等效血量：** 默认关闭，需房主在配置文件中开启。开启后按同房人数计算，1 人 `100%`、2 人 `160%`、3 人 `196%`、4 人 `217.6%`。人数变化只影响后续有效伤害，不给 Boss 补血。

关闭游戏后编辑 `%USERPROFILE%\AppData\LocalLow\Team Cherry\Hollow Knight\CoopMod.GlobalSettings.json`，保留原文件其他配置。以下示例将队友设为半透明，并显式开启 Boss 人数难度：

```json
{
  "OtherPlayerOpacity": 0.5,
  "BossHealthScaling": true,
  "BossExtraHealthPerPlayer": 0.6,
  "BossExtraHealthDecay": 0.6
}
```

透明度由每位玩家各自配置。Boss 难度使用房主开房时的配置，改动后需重新开房；`BossHealthScaling: true` 开启、`false` 关闭。已有配置显式保存的 `true` 不会被默认值覆盖，需手动改成 `false`。多人难度通过折算 Boss 所受有效伤害实现，保留原版阶段 HP 和过场阈值，普通敌人不应用此倍率。

难度入口接入 **54 种 Boss／阶段／受伤部位类型**，这个数字包含阶段和独立受伤部位，不能当作 54 个独立 Boss。本功能的实际双端战斗验证集中于格鲁兹之母和假骑士。
