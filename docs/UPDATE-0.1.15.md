# HollowConnect 0.1.15

共享永久进度开启时，队友购买鹿角站后，本机当前场景会立即走原生开站动画，关闭尚未确认的购买提示并恢复控制，无需跨场景刷新。已到达的同一进度不会再次扣费或插入动作。修复只补上原有 SaveChanges 调用，不增加轮询、超时、全房间 FSM 重启，也不共享个人地图或吉欧。

用户报告的科尼法买地图后双方持续互相不可见仍待定位。用户确认双方都买了地图，消失后队友定位仍实时更新，切换场景不能恢复、重开联机房间暂时恢复。双端日志尚不齐全。新版本在正常日志中记录入场发布和过期快照/入场拒绝的房间、visit、epoch；这些是诊断改进，不是消失问题的修复。

安装时关闭双方游戏，使用 `HollowConnect-0.1.15-windows.zip` 内一键安装器，然后重新开房。没有自动修改正常游戏或玩家存档。

请先复测鹿角站：接收者留在同一场景，分别在未交互、购买提示打开时让队友开站，确认无需换房、不会再付费且可以移动。若地图购买后的消失再次出现，保留双方 `%USERPROFILE%\AppData\LocalLow\Team Cherry\Hollow Knight\ModLog.txt` 和 `Player.log`，重开游戏前复制；需要双方日志以区分场景发布、服务器处理、快照接收和角色显示。

当前版本的专项和生产 DLL 哈希以 [运行记录](evidence/runtime-room-0.1.15.json) 为准。旧 0.1.14 的六组神居/死亡专项属于旧 DLL，不计作本版验收。历史未定位问题与这次地图可见性报告继续保留，`releaseReady=false`。
