# 收藏家战后单端卡门修复（2026-10-22）

已在现有隔离双端复现并修复。双方几乎同时进入 `Ruins2_11`，原生战斗实际位于附加场景 `Ruins2_11_boss`。由访客获得权威，永久进度共享关闭。角色碰撞启动原生战斗；注入原生伤害和实际 `HealthManager.Hit` 完成十五次处决打击，随后等待原生死亡动画，全程不强制切换 Boss 状态或直接设置击败标记。

## 原因和修复

收藏家血量归零后仍有处决阶段。`Death/Set Data` 写入 `collectorDefeated`，之后经 `Fall → Puddle → End → Send Event` 发出 `BATTLE END`。各端本地 `Battle Scene/Control` 接收该事件进入 `End`，再发 `BG OPEN`、解除镜头锁。

旧的远端事件隔离同时拦截了本地战斗控制器和门的终局通知。修复前 `repro-b` 中权威端已为 `End`、门为 `Open`；非权威端击败标记已为真，却仍为 `Start`、两扇门均为 `Close 2`。

新增 `BossGateCompletion`，仅识别已注册 Boss 的原生 `BATTLE END` / `BG OPEN`，且必须位于原生击败记录状态，或经 `FINISHED` 连接到该记录的后续状态。普通事件名称、血量归零和处决中间态均不足以开门。该例外只允许本房主／附加场景的本地挡板，以及原生收到 `BATTLE END` 后发出 `BG OPEN` 的本地控制器继续处理；普通远端关门、移动门及其它世界交互继续隔离。

动作重放和最终状态快照共用此规则。按本次进房编号及轮次保留完成通知，解决通知先到、该端本地触发器或关门动画后完成的顺序；换场、轮次变化及注销时清理。没有新增网络协议字段，没有根据击败标记扫描整个房间、删除门或跳过原生死亡演出。
