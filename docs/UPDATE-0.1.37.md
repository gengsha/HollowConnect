# HollowConnect 0.1.37

2026-10-25。完整包继续使用测试渠道，网络标识 `0.1.37-l8`，引擎 `3.0.0-hc13`。房主和所有队友使用同一个完整包并重新开房。

## 本次修复

- 银行家米莉贝利藏匿地：本机正在与她交谈时，队友攻击不会再让交谈对象被原生受击流程停用，避免对话界面无法继续、输入和暂停无法恢复。保护只限 `Ruins_Bathhouse/Banker Spa NPC` 的本机交谈期间；对话由原生流程结束，之后仍可正常追打和掉钱。
- 竞技场空战死亡落位：修复无地面阶段因找不到地面支撑而直接按正式死亡返回的问题。仍优先选择安全地面；没有合适地面时，在存活队友可接近、复活后有安全恢复路线的条件下保留空中救援点，复活后恢复原生重力与空中动作。窄平台旁缺少可站立位置时，也允许满足安全路径条件的队友从空中挥钉救援。也处理倒地后平台消失、旧点被持续危险覆盖，以及接受骨钉救援瞬间支撑丢失的重新落位。尖刺、酸池、实心墙和封门隔离检查继续生效。[专项报告](AERIAL-RESCUE-FIX-2026-10-24.md)。
- 简单钥匙新同步规则：开启共享永久进度时，按斯莱商店、泪城、古老盆地、苍白潜伏者四个固定来源共享，一人获得后，每个存档每来源各得一把。钥匙各自消费，后来加入者按来源补领；重复领取、收包或重连不会增发，也不会退还已花掉的钥匙。吉吉房间、欢乐之屋、皇家水道入口和寻神者棺材改为各自开锁、各自扣一把，不同步门锁或钥匙余额。这取代此前欢乐之屋入口开门记录共享的规则；旧存档已打开的门保留。[规则与验证](SIMPLE-KEY-SHARING-2026-10-24.md)。
- 钥匙迁移与领取提示：旧存档按本机已有原生来源标记登记“已领取”，不给原持有者重新发放，也不按钥匙余额或已开门数量猜测来源；旧标记有误时不能还原真实领取历史。关闭共享后，新领取仅归本机。共享领取钥匙时沿用原版左下角资源图标及名称提示。
- 遭遇战卡波次及迟入卡门：以喷黄色弹幕飞虫房间为直接复现，补齐非权威触发的第二波召唤请求，并保留早于本机开战初始化的死亡计数，避免清场后队友路过被封在不再出怪的房间。死亡计数修复作用于共用本地战斗流程；同名原生召唤器支持覆盖 `Crossroads_08`、`Crossroads_22`、`Deepnest_East_04`、`Deepnest_East_11`，并保留双蘑菇迟入、母体幼虫波次等相关修复。直接通关、相关回归与仅检查资产注册的范围分别记录于[专项报告](ENCOUNTER-SOFTLOCK-FIX-2026-10-24.md)。
- 愚人斗兽场：三种试炼的入口栅门按本机入场处理；后到玩家进场前可穿过已升起的左墙，进入后恢复碰撞。原生墙体和波次同步继续保留。[专项报告](COLOSSEUM-ENTRY-GATE-FIX-2026-10-25.md)。
- 包含 0.1.36 及此前其它修复；钥匙与四处门锁以本版新规则为准。
