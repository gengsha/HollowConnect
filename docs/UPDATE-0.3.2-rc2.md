# HollowConnect 0.3.2-rc2

本候选版包含 [0.3.2-rc1 的全部更新](UPDATE-0.3.2-rc1.md)，并修复队友传送。

- 修复非房主可以用 F7 选中队友，但按 F8 没有效果的问题。现在服务端会返回明确的传送结果；条件暂时不满足时会提示稍后重试。
- 在连接、断开或场景转换时清理未完成的传送请求，避免旧请求影响下一次操作。
- 保留 0.3.2-rc1 中灵魂战士、苍绿之境和王后花园的原版战斗唤醒修复。

下载与你的游戏版本匹配的 Windows 包。Legacy 对应 1.5.78.11833，Unity6 对应 1.5.12620。联机玩家须安装相同的 0.3.2-rc2。

本候选版在两个游戏版本上分别执行了完整核心测试及 17 项双端实机检查，最终二进制哈希和检查范围见发布证据。
