# 0.1.11 倒地反馈、个人死亡与入场免伤

本版将临时倒地与正式死亡分开。临时倒地等待队友骨钉击破救援暗影，不播放死亡动画，不丢吉欧、不修改死亡暗影、不触发原版死亡处罚。所有在线玩家收到一次原版受击音效，同房间在倒地点出现少量原版受击粒子。被救起者原地恢复一血、零蓝血。

倒地音效复用原版 HeroSounds 受击声，致命攻击已播放时不会再补一次。粒子来自骑士 Damage Effect 的 Hit Pt 2，缺失时回退 Hit Pt 1；发射 12 粒，最多 16 粒、缩放 0.7、粒子寿命 0.45 秒，整个物体在 1.2 秒真实时间后销毁。暂停与受击停顿不拖长生命周期。可靠 Down 事件和生命周期列表分别去重；列表先到不会漏反馈，复活后迟到的倒地事件不会重复声音或恢复倒地状态。远端 Stun 动画不再为这一临时倒地叠加完整受击效果。

最后一人倒地时，全队失败推进一次协作轮次，并清理上一轮战斗缓存。每个人使用自己在倒地时捕获的死亡场景、坐标、长椅、标记、类型、朝向、梦境返回场景及神居返回门。各自启动原版 HeroController.Die，由原版死亡预制体和 GameManager 完成动画、吉欧池、暗影放置、灵魂限制、易碎护符和地图区域例外。实现不把队友的长椅写入本人，不自行计算替代处罚。

| 情况 | 临时倒地 | 全队失败 / F6 正式死亡 |
|---|---|---|
| 普通流程 | 无死亡动画、保留钱与暗影状态 | 原版 Death 动画，吉欧转入个人暗影池，按原版放置暗影并限制灵魂，回个人长椅 |
| 梦境 Boss | 同上 | 原版 Death Dream 动画，保留钱与暗影状态，回个人 dreamReturnScene |
| 神居单 Boss / 连战 | 同上 | 原版梦境死亡和个人挑战返回入口，不统一到主机长椅 |
| 白宫 | 同上 | 原版 Death Dream 动画，但走个人长椅返回分支；无吉欧/暗影处罚 |
| 钢魂 | 救援不拦截 | 保留原版死亡规则 |

倒地玩家按 F6 主动放弃时，同样接受一次正式死亡，但不推进全队轮次、不清理存活队友的怪物缓存。离房者是模拟权威时正常移交。救援与放弃只接受服务器先成功的请求。死亡协程由原版骑士对象持有，接受后断线或取消协作等待，不会取消动画或个人加载。

双方加载完成后再释放全队屏障：本机须已进入自己的实际目的地、原场景 handle 已改变、角色就位、场景切换完成且镜头恢复。服务端逐人验证冻结的返回场景，拒绝错房间 Ready；没有明确场景的原版隐性返回接受实际合法场景。迟加入重试者没有死亡，用自己的检查点加入屏障，不补收死亡代价。断线成员从等待名单移除。

## 入场免伤

房主菜单提供“入场免伤”，默认开启，开房时固定。新场景访问或新连接会话建立一次保护；等待场景就位、原版进门移动结束、无倒地/协作加载/个人返回、恢复输入、镜头未冻结、游戏未暂停，以及本次访问和协作轮次的战斗快照提交。全部满足后连续保留 1.5 秒反应时间。期间再次失去就绪条件会重新计时；已经结束的保护不会因战斗中失控、眩晕或暂停重新开启。

普通敌人攻击在 TakeDamage 前拦截。尖刺、酸液等危险保留原版危险重生流程，通过 AfterTakeDamage 将伤害设零，避免免伤者滞留危险地形。这里不修改永久 isInvincible、玩家存档或原有音量配置。
