# HollowConnect 0.1.34

2026-10-24 重新生成完整包，合入此前同一版本下完成的修复。旧的 2026-10-23 安装包不包含这些后续修改；即使菜单版本号相同，房主和所有队友也必须更新到这次的完整包并重新开房。

- 修复失落近亲同场击败后，另一人仍能入梦、领奖灵魂不出现。共享永久进度可补齐失落近亲、灵魂暴君等一次性梦境的击败记录，并刷新已加载的入口与未领奖灵魂；精华和领奖历史仍为个人数据。见[失落近亲结算](LOST-KIN-SETTLEMENT-FIX-2026-10-23.md)和[梦境进度补齐](DREAM-SETTLEMENT-CATCHUP-2026-10-23.md)。
- 修复苦痛之路双守卫死亡后，另一端末尾封门不打开的问题；无同场队友可观战时，F6 可走个人原生死亡回程。见[苦痛之路修复](PATH-OF-PAIN-FIX-2026-10-23.md)。
- 修复收藏家开场、普通格林敬礼受击后的战吼同步可能留下永久控制锁。见[战吼修复](BOSS-ROAR-LOCK-FIX-2026-10-23.md)。
- 修复五门失败冠军开场后，另一端镜头锁区未解除。见[失败冠军镜头](P5-FAILED-CHAMPION-CAMERA-2026-10-23.md)。
- 修复五门及普通流程灵魂战士的召唤小怪所有权缺口，避免小怪悬空静滞、无法击杀。见[灵魂战士小怪修复](SOUL-WARRIOR-FOLLY-FIX-2026-10-23.md)。
- 修复结局后继续联机、返回个人检查点时，血量与灵魂等 HUD 仍隐藏的问题。返回场景入场完成后恢复原生 HUD，保留房间连接与队友状态。见[结局 HUD 修复](ENDING-HUD-FIX-2026-10-24.md)。
- 保留客机传送加入五门后的通关返回场景／入口修复及 F9 离场状态诊断，见[五门返回修复](PANTHEON-RETURN-FIX-2026-10-23.md)。此前手柄反馈、伤害榜和菜单布局改动继续保留，见[0.1.33 更新说明](UPDATE-0.1.33.md)。

版本继续使用测试渠道，网络标识 `0.1.34-l7`，引擎 `3.0.0-hc13`。共享永久进度默认开启，动态 Boss 血量与伤害榜默认关闭；已有配置保留。

最终生产 DLL 的增量构建及 `ending-hud-20261024-a1` 一组隔离双端检查通过，约 33 秒。检查先用原生 `OUT` 隐藏 HUD，分别经过 `MainMenu`／`MainMenuNoSave` 退出接口、真实 ContinueGame 与原生回椅，确认 HUD 恢复、返回者仍联机，未参与返回的队友保持正常。两端完成且严格日志通过。这是退出接口的定向夹具，没有重放完整 Boss、片尾或全部结局。

其他修复的相关核心与双端检查见各专项报告，均保留当时的生产哈希。它们属于此前构建证据，不改写为最终 HUD 构建的重测结果。本次按用户时间要求只执行打包完整性核验，没有追加游戏回归、完整房间矩阵、连续五门或跨机器 FRP 验收。
