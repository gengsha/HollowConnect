# 死档风险审计与诊断工具

本次审计覆盖 HollowConnect 生产代码中的原版 `PlayerData`、`SceneData`、场景过渡、Boss 神居上下文、死亡流程和联机断线路径。初稿是源码审计；后续已定位实际安装并完成 DLL 哈希、只读 Boss 审计及隔离双端测试，见 [全量检测历史](FULL-DUAL-DETECTION-2026-10-17.md) 和 [修复复测记录](STABILITY-FIX-VERIFICATION-2026-10-17.md)。没有读取或修改真实存档。

## 已确认并修复的高风险路径

| 路径 | 风险 | 修复 |
| --- | --- | --- |
| `BossRoomSynchronizer` 接收远端 Boss 上下文 | `BossTravel.Prepare` 会改写 `currentBossSequence`、`bossReturnEntryGate` 和静态 Boss 控制器状态。原先如果断线、场景卸载或 `EndBossScene` 抛异常，临时值可能留到下一次原版保存。 | `CoopContext` 增加提交/恢复回调；Boss 上下文应用前保存一次基线，完成原生 Boss 结束后提交，异常、换房和销毁时恢复。 |
| `CoopRuntime.WarpTo` | `BeginSceneTransition` 被接受前发生超时/异常时，原先没有覆盖所有协程退出路径；自定义 dreamGate 入口也可能残留并影响下一次传送。 | 传送上下文按事务处理；原生加载接受前始终回滚，接受后保留目标场景所需上下文；已接受加载结束后统一清理残留入口并恢复控制。 |
| 白色防御者梦境入场 | 场景已到达但 `FinishedEnteringScene`、Hero 控制、刚体、HeroBox 或镜头仍处于锁定状态，会形成“有声音、不能动、不能传送”的死状态。 | 仅限 `Dream_04_White_Defender` 的延迟恢复；不调用保存、不改资源和进度，并在断线/单人时也运行。 |
| 共享资源同步 | 远端来源如果直接禁用物体或写本地 `SceneData`，会把流程中途状态固化到原版存档，导致新人无法正常获得或存档分歧。 | 远端领取保留本地物体，使用独立原版模板播放碎片动画；重复本地交互同时阻止发奖、碎片归零和上限转换。房主权威来源与本机发奖回执分开；HKMP 全量 SaveUpdate 也会保护这些本地资源字段。 |
| 未激活召唤物的模板 FSM | 真实客机实例只有默认占位状态，却已标记预处理，无法应用房主的状态索引；接管也可能丢失本机动作订阅。该项是已确认同步缺陷，未证明会写坏存档。 | 登记前展开默认占位模板，保留已展开实例中的原生变量/动作，并使准备后的未启动实例首次 Awake 沿用同一 FSM。真实召唤链和 Unity 夹具差异证据见复测记录。 |

## 仍需实机确认的边界

- 接受原生场景加载后进程被强制终止，Unity 具体保存时机无法从项目源码证明；应在目标版本做“传送接受后断线/退出、重新读同一存档”的双端测试。
- `FinalBossCorpseContinuation` 只复制已验证的尸体结算字段，仍需要最终 Boss 的主机/客机、晚加入、断线和结算后重进测试。
- 目标游戏 DLL 已获得并完成静态审计；未逐项触发的 Boss prefab、动态子弹、召唤物和 FSM 事件仍需运行覆盖，不能把静态项目检查当成全 Boss 已验证。

## 诊断工具

- F9：打开/关闭只读面板，单人或断线状态同样可用。
- `/hc_debug show`：打开面板。
- `/hc_debug export`：导出到 `Application.persistentDataPath/HollowConnect/diagnostics/`。
- `/hc_debug recover confirm`：二次确认后只清理 HollowConnect 临时协程、传送入口和控制锁；不会调用 `SaveGame`、`ReadyForRespawn` 或 `SceneData.SaveMyState`，不会清空长椅、暗影、Boss 击杀、能力、资源或原版领取标记。
- **紧急回椅快捷键（隐藏）**：在已载入存档内按 `Ctrl+Alt+F12`，左右 Ctrl / Alt 均可。它会先断开本机联机，释放已接受的原版加载等待，然后清理残留协程和控制锁，调用原版 `ReadyForRespawn` 返回 `Town/RestBench`。确认新场景、长椅、角色和镜头就绪后调用原版 `SaveGame`，将本存档的复活点保存为德特茅斯长椅；保存未确认时会提示正常退出保存。它不执行死亡扣费，不清除永久能力、Boss 进度、资源回执或个人暗影。主菜单不触发；游戏进程完全冻结、无法执行 Update 时不能接收快捷键。实现与专项证据见 [0.1.22 更新说明](UPDATE-0.1.22.md)。

导出内容是固定字段的状态摘要和最多 256 条环形事件，包含场景、入口、Hero 控制/刚体/相机、传送/死亡状态、Boss 上下文守卫是否仍待提交、资源回执数量和共享进度数量。导出会过滤玩家名、IP、令牌和完整 `PlayerData`，适合附在问题报告中。
