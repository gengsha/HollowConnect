# HollowConnect 0.2.8 · Unity6 独立受击无敌帧修订

适用于 Windows Hollow Knight **1.5.12620 / Unity 6000.0.61f1**，包名为 `HollowConnect-0.2.8-unity6-hit-evasion-windows.zip`。包含配套 Modding API 和 Steam 模块。全员关闭游戏、完整解压、运行“一键安装.exe”更新，再重新开房。游戏内版本仍为 0.2.8，所有玩家应安装同一修订包。

本次修复多人近同时攻击会互相占用敌人短暂受击无敌时间的问题。敌人在场景权威端只有一个原生受击计时器；即使没有同步这个字段，队友攻击仍会在同一个计时器上被挡住。现在按攻击玩家分别记录原生计时器，同一玩家的骨钉和法术遵守自己的窗口，其他玩家可以同时命中。动态血量规则保持原样。

Boss 阶段无敌、方向无敌、原生直接伤害调用、特殊受击动画和骨技防多判仍遵循原有规则。计时随游戏时间推进，暂停期间不会提前到期。

本修订两版共用同一实现，Legacy / Unity6 生产与 Smoke 构建通过，17 项相关核心检查通过。Unity6 在本修订最终 DLL 上完成四组双端检查：房主权威、客机权威、动态血量与 False Knight 阶段接管、原生 Great Slash / Dash Slash / Cyclone 骨技。两端完成、严格日志和生产哈希均校验通过。详见 [本次验证记录](evidence/development-validation-hit-evasion-20261113.json)。

11 月 11 日原始适配包的 20 组检查保留为历史证据，不能视作本修订新哈希重新通过完整矩阵。本轮没有旧版实机结果，也没有验证新旧游戏混合联机。新版 API 的启动预加载异常和既有问题继续保留，见 [新版适配说明](UNITY6-0.2.8.md) 和 [已知问题](KNOWN-ISSUES.md)。

安装目录、备份链及卸载规则与原始 Unity6 包一致。安装器会拒绝旧版游戏/API 或跨游戏版本备份链；详细安装说明见 [Unity6 说明](UNITY6-0.2.8.md)。
