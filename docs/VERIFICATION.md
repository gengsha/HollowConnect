# 验证范围

当前发布为 0.2.8 / 0.2.8-l15 / HKMP 3.0.0-hc13。正式 Release 渠道与完整实机验收是两个不同记录。

0.2.8 的核心回归通过 53 项。受击停顿与 Grimm 咆哮/弓清理专项使用与生产 DLL 匹配的同机双端流程通过 7 组；共享血量面具碎片、四片转化和资源回执流程通过 linked-f、resources-h；Silver 普通房主与普通客机流程通过 silver-m、silver-o。Silver 权威交接 silver-p 在重新寻找原生领奖交互范围处失败，未计为通过。完整矩阵没有因本次正式打包重新执行。

本轮共享血量专项没有复现“两名玩家都没有获得面具碎片”的旧反馈；这保留为待现场回收的报告，不把通过的四片转化流程当成根因证明。真实跨机器 Steam 邀请、FRP、中继、三人观战、所有 Boss 全招式、完整连续五门和所有存档持久化组合仍未获得完整认证。

验收要求双方完成、无迟到失败标记、严格日志通过，并记录实际生产 DLL、游戏依赖和测试逻辑。只出现 done、单端 FINAL PASS、后续重试成功或版本号相同都不足以复用结果。隔离启动曾有原生 SetupHeroRefs 异常，严格模组日志通过不代表整个 Unity 输出无异常。

构建和定向测试见 [开发指南](DEVELOPMENT.md)，专项入口见 [测试目录](TEST-INVENTORY-2026-10-18.md)。本次正式打包按用户请求保留未重测标记，未将旧哈希追认为 0.2.8 完整验收。
