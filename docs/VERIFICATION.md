# 验证范围

当前发布为 **0.2.7 / 0.2.7-l14 / HKMP 3.0.0-hc13**。正式 Release 渠道与完整实机验收是两个不同记录。

升版前的统一显示同步构建通过 102 项核心检查、20 组双端检查，包含原生野兽／席奥、地刺、受限链路竞技场和 12 项房间矩阵。随后原生菜单构建通过 9 项相关检查、4 组双端流程，覆盖菜单、可选 Steam 模块缺席、IP 加入／重连／重开房及 Steam 单账号原生流程。两阶段绑定不同的生产哈希，不能合并为同一最终哈希验收。0.2.7 升版只改显示／程序集版本和网络兼容标识；执行构建、安装流程及包核验，没有重跑核心或游戏矩阵。

真实跨机器延迟／FRP、三人观战轮换、所有 Boss 全招式、完整连续五门、完整剧情和所有存档持久化组合均未因这次发布获得完整认证。[已知问题](KNOWN-ISSUES.md) 继续保留，后续通过不会自动关闭原因未明的失败。

验收要求双方完成、无迟到失败标记、严格日志通过，并记录实际生产 DLL、游戏依赖与测试逻辑。只出现 `done`、单端 `FINAL PASS`、后续重试成功或版本号相同都不足以复用结果。隔离启动曾有原生 `SetupHeroRefs` 异常，严格模组日志通过不代表整个 Unity 输出无异常。

构建和定向测试见 [开发指南](DEVELOPMENT.md)，专项入口见 [测试目录](TEST-INVENTORY-2026-10-18.md)。本次发布没有重新运行游戏或改变上述验证状态。
