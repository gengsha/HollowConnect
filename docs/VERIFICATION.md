# 验证范围

当前发布为 **0.2.5 / 0.2.5-l12 / HKMP 3.0.0-hc13**。正式 Release 渠道与完整实机验收是两个不同记录。

升版前的 0.2.4-l12 构建通过 71 项相关核心检查、26 组同机真实 UDP 双端检查：9 组主动观战、2 组原生大黄蜂、12 项房间矩阵、3 项既有专项。它们绑定旧构建哈希。0.2.5 升版后执行生产／安装器构建和包完整性检查，没有再次运行游戏，不能把此前结果追认为新哈希的实机验收。

真实跨机器延迟／FRP、三人观战轮换、所有 Boss 全招式、完整连续五门、完整剧情和所有存档持久化组合均未因这次发布获得完整认证。[已知问题](KNOWN-ISSUES.md) 继续保留，后续通过不会自动关闭原因未明的失败。

验收要求双方完成、无迟到失败标记、严格日志通过，并记录实际生产 DLL、游戏依赖与测试逻辑。只出现 `done`、单端 `FINAL PASS`、后续重试成功或版本号相同都不足以复用结果。隔离启动曾有原生 `SetupHeroRefs` 异常，严格模组日志通过不代表整个 Unity 输出无异常。

构建和定向测试见 [开发指南](DEVELOPMENT.md)，专项入口见 [测试目录](TEST-INVENTORY-2026-10-18.md)。整理文档没有重新运行游戏或改变上述验证状态。
