# HollowConnect 0.1.25（2026-10-18）

新增房主规则 **Boss击败后解除暗影**，默认开启，需同时开启暗影救援；开房前设置，修改后重新开房生效。Boss 真正击败时，同房间的暗影玩家自动恢复为 **1 红血、0 蓝血**，清理双方暗影视图并恢复人物、输入、物理和镜头。存活玩家保留原有血量；自动解除不发放击破暗影救援的 33 点灵魂。

## 触发与同步

规则接入公共 Boss 完成入口：神居原生 `EndBossScene`、剧情 Boss 的终结死亡／击败记录，以及七名梦境战士的实际战斗结束。假骑士破甲、灵魂大师／暴君第一阶段和普通敌人不作为击败；守望者骑士按整组判断。神居多 Boss 与脚本控制的空 Boss 列表使用原生战斗完成信号。

只有当前房间权威能报告胜利。服务器通知该房间当前访问的玩家；本机若正处于暗影状态，捕获当前死亡序号再可靠请求恢复。这样不要求不同客户端的 Down 与击杀消息按共同顺序到达。服务器确认房间、访问、轮次和死亡序号后才解除 Down 并增加生命版本；一次胜利对每位玩家最多恢复一次。已放弃、全队重试、其他房间及旧访问不受影响。

复活共用暗影救援的安全落点检查：先重新核对原落点，再寻找原生有效支撑；确实没有可用落点时，保留原生个人返回保障，不把玩家释放到空中。没有新增存档写入或常驻的全场景扫描。
