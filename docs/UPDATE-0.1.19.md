# HollowConnect 0.1.19

本版用于测试 Boss 与弹幕的连续运动，沿用普通小版本名称。

- 已接入实体同步的 Boss、普通怪物和弹幕使用短缓冲位置平滑，减少后入场一方逐包跳动的现象；停止、初始快照、长间隔及大幅跳跃有独立处理。
- 子物体位置和连续动画也使用公共平滑/播放路径。副本动画关闭游戏逻辑回调，伤害、血量、招式阶段与死亡继续由原有权威规则决定。旋转、缩放、显隐和所有特殊脚本动画未全部平滑。
- 按住 **F5** 查看本存档累计死亡榜。倒地计一次，被救起也计入；救援和正式返回不重复加次数。保存名字与累计值，重开房间、正常保存后隔日继续均保留，离线队友仍在榜。
- 死亡榜由 Modding API 随游戏正常保存到独立的 `user槽位.modded.json`，不修改原版存档格式，卸载 HollowConnect 后原版仍可读取存档。同名合并、改名另列；旧版没有记录的死亡无法补算。

所有人关闭游戏，完整解压 `HollowConnect-0.1.19-windows.zip`，运行 **一键安装.exe → 安装 / 更新**，再重新开房。菜单应显示 **HollowConnect 0.1.19 / HKMP 3.0.0-hc11**。本版更新了同步格式，房主与队友都须安装同一完整包。FRP 配置沿用。

建议先让一人入 Boss 房间，队友几秒后跟进，观察后入场一方的 Boss 跑动、冲刺、弹幕飞行和连续动画；同时留意伤害判定是否自然。退出游戏再读同一存档、重新开房，可顺便确认 F5 死亡榜保留。
