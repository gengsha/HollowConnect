# HollowConnect 0.3.2

- 队友传送改用聊天命令 `/tp 队友名`，由房主开启。队友正在切换场景时，客户端会在短时间内重试，并在冷却或无法传送时提示原因。F7 仍用于观战切换。
- 聊天框支持 ↑ / ↓ 浏览本次游戏的发送历史，输入 `/` 后会显示半透明提示。Tab 补全命令与在线队友名，回车发送。
- 修复神居四门纯粹容器开场后客端镜头仍锁定的问题。五门沿用原版开场和战斗镜头行为。
- 新增默认关闭的本机队友状态条。它显示姓名、到房间服务器的延迟和原版面具，倒地使用暗影提示。它可独立于伤害占比榜开关，共享血量开启时停用。
- 改进皮肤兼容性，包括《死亡细胞》这类图集。Legacy 支持通过 Custom Knight 使用皮肤。Unity 6 可使用联机菜单中的兼容皮肤选项。安装方法见 [皮肤兼容说明](SKIN-COMPATIBILITY.md)。
- 包含候选版中苍绿之境、王后花园、灵魂战士和假骑士的战斗唤醒修复。

Legacy 适用于 Hollow Knight 1.5.78.11833，Unity 6 适用于 1.5.12620。请按游戏版本下载 Windows 包。房间成员应统一升级至 0.3.2。

本次按改动执行核心、双端专项和安装器检查。豪华钥匙开门至获取黑波沿用 RC3 的四人实测结果。详见 [发布验证](evidence/development-validation-0.3.2.json) 和 [已知问题](KNOWN-ISSUES.md)。
