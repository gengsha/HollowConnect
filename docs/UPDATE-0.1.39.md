# HollowConnect 0.1.39

2026-10-25。完整包继续使用测试渠道，网络标识 `0.1.39-l8`，引擎 `3.0.0-hc13`。房主和所有队友更新同一完整包并重新开房。

## 本次更新

加入房间后，每次选择已有存档或启动新档，都会先显示空洞骑士原生样式的「确认加入联机」菜单：

> 共享进度可能永久改变存档

房主开启「共享永久进度」时，额外显示：

> 请确保你选择的存档不会覆盖房间原有进度

默认选中「取消」。取消或按返回键会回到选档页面，保留当前连接；选择「确认加入」后才读取已有存档或启动新档。确认期间断线会清理待执行操作，返回可操作的连接菜单。警告每次都会出现，不按双方进度差距判断；新增的房间进度提醒只依据房主的共享开关显示，不读取加入者自己的开关。菜单不显示条件说明和感叹号。

包含 [0.1.38 战斗入口修复包](UPDATE-0.1.38-BATTLE-ENTRY-FIX.md)、[0.1.38](UPDATE-0.1.38.md) 及此前修复。
