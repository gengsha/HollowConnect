# HollowConnect 0.1.30 更新日志

2026-10-21，测试渠道。按用户要求将现有源码升版并打包为 **0.1.30**，合入此前未随 0.1.29 ZIP 交付的救援、梦境 Boss 和索敌修复。引擎仍为 **HKMP 3.0.0-hc12**，附加网络标识为 **0.1.30-l2**；房主和所有队友须更新同一个完整包并重新开房。

## 本次交付的变化

- **保留无眼第一次修复：共享提灯后看不到 NPC，接受挑战封场却不出 Boss。** 原版无眼的提灯前置条件曾被误读为“是否亲自购买过提灯”，忽略了有效共享能力；现在读取当前实际提灯能力。本地拾取经历仅用于真正的能力拾取对象及已核对的拾取布景。该修复已经随 0.1.29 交付，0.1.30 继续包含；双方未打过无眼时可正常挑战、战胜后各自领取一次 200 精华。见[第一次无眼修复](NO-EYES-NET-AUDIT-2026-10-20.md)。
- **保留无眼第二次修复：已领取精华的客机陪打后，交互出现空文本和 `SUPER / MAIN / SUB` 占位标题。** 客机已经领过 200 精华时，网络开战与死亡广播曾把本应结束交互的 NPC 重新唤醒，而原版没有初始化其对话文本。现在保留该玩家原生的已领奖状态，仍可参与队友的网络 Boss 战；战后墓碑检查显示正常文本，不重复发精华。未领奖玩家仍走各自原版领奖流程。该修复随后也合入 0.1.29，0.1.30 继续包含；保护适用于七位梦战士的共同模板，原专项以无眼和泽若作运行验证。见[第二次无眼修复](NO-EYES-COLLECTED-2026-10-21.md)。
- **Boss 房内最后一名可战斗玩家倒地时，结束本场。** 修复“一人放弃救援、正在赶路，房内另一人倒地后 Boss 战仍不结束”的规则。只让本场倒地者返回个人原版复活点，不等待或挪动房外赶路队友；已进房仍在加载的队友不会被误判为离场。
- **新增每人救援次数与观战 Beta。** 暗影救援默认不限次数，可选 1／2／3／5／10 次；成功被骨钉救起或 Boss 胜利解除暗影消耗一次，真正坐椅子恢复，死亡回椅、换房和重试不补次数。“救援耗尽后观战（Beta，房主）”默认关闭，也能在关闭暗影救援时独立开启；观战跟随同房存活队友，F7 切换，F6 提前返回。胜利或本场失败时按个人原版死亡规则返回，不免费复活。
- **修复剧情失败冠军本体、头部漏同步。** 原对象名 `False Knight Dream` 没有匹配注册表，导致双方独立扣血和推进阶段；现在明确登记本体与头部。原生破甲、露头、死亡、个人返回及精华领取已有专项记录。
- **修复戈布陪打后的附加场景残留。** 不同领奖历史下，客机通过网络补加载 Boss 场景后，现在交回原生卸载组件管理；离房时清理，不让旧场景留在后续房间。该修复不关闭历史“悬崖疑似地形重叠”的另一项报告。
- **Boss 倒地索敌改为同房存活队友。** 已复现黄蜂权威倒地后仍朝隐藏骑士的死亡位置攻击。现在在已核对的原生目标读取中临时选择有效活人，队友移动后继续跟随，救起后恢复原生目标；不移动隐藏骑士、救援暗影或摄像机，不持久改写 FSM 的目标引用。尚未逐 Boss 验证全部招式。

同时保留先 Connect 再选档的资源补齐、远端碎片直接结算与原版左下角提示。世界资源按来源取并集；骨钉等级、矿石消费、精华和吉欧继续各自独立。
