# 客机通关五门后无法交互

## 原因与修复

客机经队友传送加入神居流程时，原实现同步了序列、索引和绑定，却没有同步完整的通关返回地址。原生结算界面会读取 `dreamReturnScene` 和 `bossReturnEntryGate`，因此可能读取客机之前留下的垃圾坑地址和空入口。空入口只结束 GameManager 的加载状态，角色仍处于 `EXITING_SCENE`，导致无法移动或交互。

0.1.34 在房间上下文、玩家位置消息及服务端传送回复中携带完整返回场景和入口；序列与单独神居 Boss 共用此信息。取消或拒绝上下文时，两项返回信息一并回滚。无效返回场景不能覆盖已接受的信息。

修复发生在传送准备阶段，继续由原生结算与入场流程恢复操作。没有添加全场景定时强制解锁。F9 现在能提示“原生加载已结束、角色仍在离场”的遗漏状态。

网络格式为 `0.1.34-l7`，房主与所有客机需更新同一完整包并重新开房。

## 验证边界

本轮只检查相关核心逻辑、真实双端传送加入、原生结算界面返回路径和包完整性。结算检查从结果界面定点开始，不等同于连续打通五门，也未重跑所有 Boss 或三人跨机器 FRP。具体本轮记录见 [0.1.34 更新说明](UPDATE-0.1.34.md)。

用户诊断和个人日志只保存在本地分析目录，不收入安装包或源码包。
