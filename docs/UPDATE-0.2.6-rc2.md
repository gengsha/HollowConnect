# HollowConnect 0.2.6-rc2

2026-11-02。本地 Windows 完整安装包与对应源码包，暂不发布 GitHub。
游戏内版本为 `0.2.6-rc2`，网络标识为 `0.2.6-rc2-l12`，HKMP 引擎仍为 `3.0.0-hc13`。
所有队友须更新同一完整包并重新开房。

## 本次变化

- 加入 Steam 好友联机预览模块：创建好友房间、打开邀请界面、接受邀请、从好友列表或游戏内好友房间列表加入，以及 `+connect_lobby` 启动参数接入。
- Steam 消息经本机 UDP 桥接进入原有 HKMP 流程，伤害、Boss、救援、存档和房间逻辑共用；保留原有 IP／域名／端口入口。
- 已有游戏或连接时暂存邀请，由玩家返回主菜单后加入；取消、退出、离线和旧邀请清理限定在模块拥有的会话。
- 救援复活后使用与原生受伤相同的无敌时间，包括坚硬外壳护符的延长效果。

## 安装与使用

完整解压 `HollowConnect-0.2.6-rc2-windows.zip`，关闭游戏后运行 **一键安装.exe**。
包内已包含 `HollowConnect.Steam.dll` 和匹配的 HKMP，不需要另找 Steam SDK 或替换游戏原装 Steam DLL。
Steam 模式面向 Windows 64 位 Steam 版；主菜单的联机面板点击 `Steam...` 或按 F10。
详细步骤见 [Steam 联机说明](STEAM-MULTIPLAYER.md)。原有 IP 联机操作继续适用。
`HollowConnect-0.2.6-rc2-source.zip` 提供本次对应源码与第三方许可。

## 同版本安装器修订

修复游戏退出后残留零线程进程记录导致的“游戏仍在运行”误判。

此修订只改安装脚本，游戏 DLL 与上述 rc2 包相同，记录见 [安装器修订验证](evidence/installer-fix-0.2.6-rc2.json)。

## 未发布开发修复（2026-11-03）

以下内容仅存在于当前开发构建，尚未重新打包、安装或发布。上文对应的历史安装包及其验证记录仍保留原哈希。

- 修复竞技场进场大包在丢包后不断累积重发、最终超过消息上限并堵塞后续同步的问题。完整状态去掉过期副本，大包压缩后分片；重发分批发送，保留可靠事件及其原始顺序，迟到确认可以撤销已排队重发。Steam 桥接与原有 IP／内网穿透共用这部分处理。
- 为活动实体补发静止时的绝对位置和朝向，避免最后一次移动包丢失后，客机停留在旧位置。
- 修复巨型斩、冲刺斩在特殊受击动画及共享血量的多个碰撞体下重复触发命中特效、喷血的问题。每次独立出招重新计数；客机保留正常命中特效和灵魂反馈，实际扣血由权威端负责，避免重复预测扣血。
- 保留旋风斩原生多段命中；本轮没有独立复现用户所说的异常旋风斩喷血，不能据此宣称该项已全部解决。
- 减少加载时无主角情况下，由无关动画触发的重复错误日志。网络标识改为显式的 `0.2.6-l13`，避免候选版长名称被截断后丢失协议修订号；后续交付时双方必须使用同一完整构建。

当前冻结 DLL 的 93 项相关核心检查通过。所选 18 组双端游戏检查中，17 组通过、1 组失败：竞技场、60／20 帧原生剑技、重复喷血复现条件、受限链路第 1～34 波、伤害平衡和不加载 Steam 模块的 IP 流程通过；12 项房间矩阵为 11 项通过、1 项失败。通过项核对了双端完成、严格日志和实际 DLL 哈希，见 [本次开发验证](evidence/arena-lag-nailarts-development-2026-11-03.json)。

失败项是大黄蜂客机先进入后的断线交接压力测试：Boss 停在 `Thrown`，针失活，未进入原生回收动作。其表现与 10 月已保留的 `reconnect-inactive-needle-unresolved` 一致，根因仍未确定，本次改动对触发概率的影响也未确定。保留本次失败，不以重试通过替换，也不宣称房间矩阵全部通过。

受限链路模拟单向 40 毫秒延迟、每方向 128 KiB/s 限速、1% 分片丢失；使用同机隔离双端，不能代替真实跨机器的 Steam／内网穿透验收。竞技场使用加速原生伤害验证波次推进，不代表正常武器全程通关或断线离线继续战斗已通过。
