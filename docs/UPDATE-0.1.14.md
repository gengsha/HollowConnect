# HollowConnect 0.1.14

按用户“直接更新一个小版本，别修复版”的要求，将菜单、联机配套模块和安装包版本更新为 0.1.14。安装包为 `HollowConnect-0.1.14-windows.zip`，对应源码为 `HollowConnect-0.1.14-source.zip`，没有修复版、试玩或构建号文件名后缀。旧包保留。

本版包含协作死亡/返回时的原生重力恢复，以及灵魂法师系列下砸危险物的预制体与动作字段元数据缓存。没有增加新玩法、削减攻击或升级引擎协议；HKMP 仍为 3.0.0-hc10。此前根因与对照见[复活与下砸专项](RESPAWN-SOUL-SLAM-2026-10-14.md)，该报告的旧 1f5efe0 哈希与本版不同。

## 验证

当前构建与实际运行记录见[0.1.14 证据](evidence/runtime-room-0.1.14.json)，打包范围与校验记录见[本次打包记录](evidence/playtest-authorization-0.1.14.json)。版本变化后重新构建并按新 DLL 哈希验证，没有把旧版本的通过改成新版本通过。

生产构建为 `803234c2e451ddb5c98f7d0eaa3949d2045cde36`。读取实际程序集确认菜单、客户端与服务端版本均为 0.1.14；143 项回归、14 项严格日志检查通过。六组新哈希的双客户端运行通过：普通 F6/全队回椅、神居和梦境个人返回、灵魂大师/暴君房主模拟、暴君房主显示副本、暴君二阶段原生下砸。每组都核对双方完成标记、停机后日志和包内三个生产 DLL 哈希。

安装器源码没有修改；前一次流程复测被路径不可读的现有游戏进程拦截，本次未绕过该检查或停止未知进程，也未将其余未完成项目记作通过。打包后核验载荷、依赖、全部归档内容与文档链接，保留实际验证范围。

本版仍有[历史未解决问题](evidence/runtime-blockers-0.1.14.json)：大黄蜂投针接管后回收、假骑士再次破甲未露头、一次来源未明的镜头冻结。全部 Boss/连战、真实双机 FRP、飞行中接管及三四人玩法未完整验收，`releaseReady=false`。下砸缓存减少接收端开销，仍需在用户两台机器交换先入顺序复测。

## 更新

1. 房主和全部队友正常退出游戏，完整解压 `HollowConnect-0.1.14-windows.zip`。
2. 双击“一键安装.exe”，点击“安装 / 更新”。无需先卸载；可自动发现 Steam 库或手选游戏目录。
3. 双方确认菜单显示 HollowConnect 0.1.14，使用同一个完整包，重新开房和进入挑战；FRP 的 UDP 设置沿用原配置。
4. 在原故障房间复测全队死亡后连续跳跃和灵魂暴君一、二阶段下砸；双方分别先入，记录哪端掉帧。

发生问题时，重开前保存双方 `%USERPROFILE%\AppData\LocalLow\Team Cherry\Hollow Knight\ModLog.txt`，附房间、先入顺序及是否刚死亡/传送/重连。安装器保留最初备份、存档和皮肤；正常游戏未自动更新。
