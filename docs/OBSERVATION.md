# 观战（Beta）

主动观战和死亡观战是两个独立选项，默认都关闭。

| | 主动观战 | 死亡观战 |
|---|---|---|
| 开启位置 | 本机菜单「主动观战（Beta，本机）」 | 房主开房前开启「救援耗尽后观战」 |
| 进入 | 落地后按 F4，同房须有存活队友 | 按房间规则在倒地、救援耗尽或放弃救援后进入 |
| 切换目标 | F7 | F7 |
| 主动退出 | F4，回德特茅斯长椅并保持联机 | F6，按原版死亡规则回自己的复活点 |
| Boss 动态增血人数 | 不计入，回椅途中也不计入 | 同房仍计入，倒地玩家也计入 |

主动观战期间，本体隐藏、关闭碰撞和物理模拟，不受伤、不攻击、不参与 Boss 索敌。暂停只打开菜单，恢复后仍在观战；期间不能传送。

再次按 F4、无同房存活目标或断线时，主动观战者走原生德特茅斯长椅流程。已开始的原生加载先完成，再回椅。回椅不算死亡、不扣吉欧、不创建或清除暗影、不增加死亡统计；长椅会成为自己的复活点。共享血量模式下，单人退出观战不会补满团队血条。

观战者不算能够继续战斗的存活成员。其余战斗玩家全部倒下时，仍触发原有团灭流程；主动观战者返回德特茅斯，和队友一起等待加载完成。死亡观战者的 Boss 胜利复活、提前返回和救援额度沿用房主规则。

主动观战在升版前覆盖了 9 组双端专项及 2 组原生大黄蜂检查；未做三人目标轮换和全部 Boss 组合验收。详见 [验证范围](VERIFICATION.md)；完整开发记录保存在 [0.2.5 发布时的报告](https://github.com/gengsha/HollowConnect/blob/c1a6d16fb5cf14b1f8470bf8c8b18b8f74349a2b/docs/VOLUNTARY-OBSERVATION-2026-10-30.md)。
