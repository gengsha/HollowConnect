# HollowConnect 0.3.3

面向 Windows 的 Legacy 1.5.78.11833 和 Unity6 1.5.12620。请按游戏版本选择安装包，同一房间的玩家应使用同一模组版本。

## 游玩与界面

- **梦之钉可以从移动中的队友获得灵魂。** 挥击须命中同一场景里存活队友的身体。每次命中奖励 16 或 17 点，两次合计 33 点，沿用游戏的灵魂容量。
- **新配置默认使用灵活 Boss 索敌。** 适配的 Boss 优先锁定最近的同房存活玩家，在空闲或追逐时可以换目标。房主可在开房前切回「原版」。已有配置沿用已保存的选项。
- **聊天栏恢复显示输入中的文字。** 继续支持指令补全和输入历史。`/tp 队友名` 默认对全房开放，满足传送条件时自动放行。带空格的名字写作 `/tp "队友 名"`。房主可退出游戏后在 `CoopMod.GlobalSettings.json` 中修改 `AllowTeleport`，重新开房生效。[聊天命令与配置路径](../README.md#常用按键)
- **补充了简体中文、英语和日语界面。** 覆盖皮肤管理、索敌说明和 Benchwarp 联机限制提示等内容。

## 皮肤管理器

在「模组 → HKMP → 客户端设置 → 皮肤管理器」打开皮肤目录，放入皮肤并点「重新扫描」。从「原版外观」开始左右循环切换，选择会保存在本机，离线也能换装。HKMP 的旧「皮肤」和「队伍」选项已锁定。

房间默认开启皮肤分享，本机「查看队友皮肤」也默认开启。联机时各自安装需要显示的皮肤包，并保留相同的皮肤文件夹名。客户端按皮肤标识从本机匹配图集，找不到对应文件时显示原版。关闭「查看队友皮肤」只改变自己看到的外观。旧 `HKMP/Skins` 皮肤可以直接扫描，《死亡细胞》一类兼容 PNG 图集可放进 `HKMP/SkinPacks`。[安装与共享说明](SKIN-COMPATIBILITY.md)

## 第三方模组兼容

| 模组 | 这次适配的行为 |
| --- | --- |
| Benchwarp | 在可安全传送时，本机可以使用 Benchwarp 回椅或通过门传送，并保持联机。切图、救援或神居连战期间会拦截。共享血量房间请正常坐椅，Benchwarp 回椅会被禁用。 |
| Enemy HP Bar | 队友晚进同一场景时，已受伤敌人的血条会按同步后的当前血量和满血基准显示。 |
| MapChanger、Vanilla Map Mod、AdditionalMaps | 地图额外区域支持显示队友位置。神居大厅已验证队友图标与 Vanilla Map Mod 图钉能同时显示。额外图层关闭或本机缺少图层时，会显示队友所在的房间名。 |
| QoL | 联机期间临时停用「跳过守梦者吸收」，保留原版剧情和同步流程，退房后恢复原设置。苦痛之路末尾双守卫的 `InfinitePoP` 重战也有专项验证。 |
| Custom Knight | 皮肤管理器可读取兼容版本的 PNG 皮肤，Custom Knight 自己换装也会反映到列表。皮肤里的视频、场景替换和脚本等仍由 Custom Knight 处理。 |

第三方模组和各自的依赖请按游戏版本单独安装。Benchwarp、Enemy HP Bar、地图组合和 QoL 的专项验证使用 Legacy 开发构建，皮肤管理与队友显示的专项覆盖两种游戏版本的开发构建。

## 更新与卸载

退出游戏后完整解压安装包，运行 `HollowConnectInstaller.exe` 或 `一键安装.exe`。已有原始备份记录的安装会先备份，再在 `Mods/HKMP` 原地更新包内文件，保留皮肤目录和其他本地文件。卸载使用最初的安装备份记录。

[English installation guide](INSTALL-EN.md) · [日本語インストールガイド](INSTALL-JA.md) · [已知问题](KNOWN-ISSUES.md)

## 验证范围

正式包对应的验证包括 10 项核心检查、19 项安装器检查和 5 组双客户端实测。两种游戏版本均验证了命中移动队友获得灵魂，以及简体中文、英语和日语的运行时切换。Legacy 另外验证了菜单指针交互。Steam 好友联机模块随包提供，仍处于预览阶段。完整房间矩阵与 Steam 双账号联机留待专项验证。[正式版验证记录](evidence/development-validation-0.3.3.json)
