# HollowConnect 0.3.3

面向 Windows 的 Legacy 1.5.78.11833 和 Unity6 1.5.12620。请按游戏版本选择安装包，同一房间的玩家应使用同一模组版本。

## 游玩变化

- **梦之钉可以从移动中的队友获得灵魂。** 挥击须命中同一场景里存活队友的身体。每次命中奖励 16 或 17 点，两次合计 33 点，沿用游戏的灵魂容量。
- **新配置默认使用灵活 Boss 索敌。** 适配的 Boss 优先锁定最近的同房存活玩家，按空闲和追逐时机换目标。房主可在开房前切回「原版」。已有配置沿用已保存的选项。
- **皮肤管理器支持离线换装和联机显示。** 在「模组 → HKMP → 客户端设置 → 皮肤管理器」打开皮肤目录，重扫后左右切换。双方装有同名皮肤包并开启相应的显示选项时，就能看到队友所用的皮肤。[安装与共享说明](SKIN-COMPATIBILITY.md)
- **聊天栏显示已输入的文字。** 继续支持指令补全、输入历史和 `/tp` 传送指令。
- **补充了简体中文、英语和日语界面。** 包括皮肤管理入口与操作提示、索敌说明及 Benchwarp 联机限制提示。

## 更新与卸载

退出游戏后完整解压安装包，运行 `HollowConnectInstaller.exe` 或 `一键安装.exe`。已有原始备份记录的安装会先备份，再在 `Mods/HKMP` 原地更新包内文件。皮肤目录和其他本地文件会保留。卸载使用最初的安装备份记录。

## 验证范围

通过 10 项核心检查、19 项安装器检查和 5 组双客户端实测。两版均验证了命中移动队友获得灵魂，以及简体中文、英语和日语的运行时切换。Legacy 另外验证了菜单指针交互。Steam 好友联机模块随包提供，仍处于预览阶段。完整房间矩阵与 Steam 双账号联机留待专项验证。
