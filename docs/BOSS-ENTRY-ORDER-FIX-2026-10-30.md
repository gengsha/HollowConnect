## 实现

格鲁兹之母：收到权威 FSM 状态时，确认它可从原生 START 动作沿原有状态转换到达，再补发给该房间中仍等待 START 的本地 Battle Control。沿用原生 Music → Start、七只幼虫计数和原生关门／开门；睡眠快照不会启动战斗。限定实体类型、Big Fly Control、房间和本地控制器结构，不以血量零代替收尾。

螳螂领主：恢复已有四字节零值挑战请求的服务器转发。只接收当前访问／轮次、Fungus2_15、已有未退役实体上的精确请求，且只发给同房的当前场景权威；普通客户端实体状态仍受原有权威限制。权威接受后通过原有提示消息通知观察者，晚进入快照只隐藏提示，不重新开战。组件拒绝重复请求，防止重复改写原生挑战状态。

本地原生提示实际取得操作权时记录该次挑战。仅该玩家的本地笼子接收相应王座的 CAGE DOWN；确认原生 Regain Control 状态中的恢复操作／动画控制及关闭 disablePause 动作后，允许其对应的当前或后续快照释放这次操作锁。其它玩家、房间、访问和任意方法调用不能利用此例外。

未新增网络消息类型或字段，未改变场景权威选举、访问／轮次校验或重置生命周期。范围是已有挑战请求的路由与两个原生局部流程，最终范围为直接受影响专项及本地屏障隔离回归，不扩大为完整房间矩阵。
