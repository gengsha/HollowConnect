# HollowConnect 0.1.38 战斗入口修复包

2026-10-25。包名为 `HollowConnect-0.1.38-playtest-battle-entry-fix`，与原 `HollowConnect-0.1.38` 包分开保留。游戏内版本仍为 0.1.38，网络标识仍为 `0.1.38-l8`，引擎 `3.0.0-hc13`。房主和队友都使用同一个修复包并重新开房。

修复黑波前灵魂战士房间中，队友进入中央关门，但负责敌人的玩家尚未进入中央、导致 Boss 不启动的问题。符合原生结构的本地 Boss 战斗入口现在会可靠地请求负责敌人的一端启动原生战斗；门和镜头继续跟随自己的入场，战斗已结束则取消延迟关门。

在完全相同的生产 DLL 哈希上通过 8 项相关核心检查和 6 组同机双端定向实测：双方分别先入场、双方正常入场、提前结束后再入场、真实断线接管并重连，以及苦痛之路双守卫特殊控制器。双端完成标记和严格日志均通过。Boss/守卫结束流程使用原生健康伤害边界，召唤物接管另有真实骨钉碰撞验证。没有完整回归、三人或异机网络认证。

特殊无计数器检查仅覆盖被新适配器排除的原生双守卫房，不保证所有假设的无计数器 Boss 结构。已有未解记录仍随测试渠道保留，不将本包标记为正式发行验收通过。
