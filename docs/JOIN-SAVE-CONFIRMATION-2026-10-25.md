# 入房选档确认菜单（2026-10-25）

加入房间后，每次选择已有存档或启动新档，都会先显示原生样式的「确认加入联机」菜单，固定提示：

> 共享进度可能永久改变存档

房主开启进度同步（「共享永久进度」）时，另显示：

> 请确保你选择的存档不会覆盖房间原有进度

该条件使用连接握手中房主下发的世界模式，不读取加入者自己配置的共享开关。条件说明及感叹号不显示在菜单中；缓存菜单也在每次打开时刷新文字。

默认选中「取消」。按确认键直接取消，或按返回键，都会回到选档页，保留当前连接；选择「确认加入」后才读取已有档或执行新档启动。确认菜单始终显示，不取决于房主共享开关、双方进度差距，也不区分普通、钢魂、神居新档；新增的房间进度提醒按上述房主开关决定。再次选档会再次提示。

菜单使用 Modding API 提供的 Hollow Knight 原生标题、花纹、按钮、导航与淡入淡出，中文固定使用原生 CJK 字体。打开警告前显式隐藏原生选档页，避免两个界面重叠。取消不会向原先的选档完成回调发送 `false`，因此不会触发客户端断开连接；退出选档页本身的「返回」仍保留原来的退出连接行为。

实现入口：`src/HKMP/Ui/SaveJoinConfirmation.cs`，由 `UiManager.OpenSaveSlotSelection(..., confirmJoin: true)` 启用。创建房间的选档流程继续使用原先的启动回调。没有修改进度合并规则、网络消息或 Boss 行为。

测试计划及逐组状态：`.analysis/join-save-confirmation-20261025/`。本轮只选择直接相关的入房流程和共享奖励选档专项，使用现有隔离副本；不生成发布包。
