# HollowConnect 0.1.27（2026-10-20）

本版交付共享进度入队核对和关闭共享后的本地世界模式，并补齐设置菜单。使用测试渠道；Windows 包为 `HollowConnect-0.1.27-windows.zip`。所有玩家更新同一个完整包，再重新开房。引擎标识为 `3.0.0-hc12`，附加网络标识为 `0.1.27-l1`，旧构建不能混连。

## 进度共享开启时

- **默认开启共享永久进度。** 新配置采用开启，旧配置明确保存的关闭仍保留。房主在模组菜单「共享永久进度（房主）」中设置，开房时固定规则。
- **每次加入或重连核对进度。** 合并双方已收集的永久能力、法术、骨钉剑技、按开关共享的护符，以及白名单中的 Boss、守梦者和永久开门标记。能力互补、法术等级取较高值，完整共享范围见[永久进度白名单](SHARED-PROGRESS.md)。
- **资源按来源共享一次。** 8 个护符槽、16 个面具碎片、9 个容器碎片、6 个苍白矿石来源分别记录 ID，合并历史来源并补给各自尚未领取的部分。已记录领取但实际缺失的护符槽、面具或容器总量可在入队核对时补差。
- **骨钉强化和消费各自计算。** 不复制队友骨钉等级或基础伤害，不返还已经花掉的矿石。精华、吉欧、地图探索记录、装备及未列出的任务状态不进入这份进度并集。
- **保留本地领取过程。** 共享到账不会提前移除尚未本地领取的奖励；碰到时仍执行原版领取和过场，已到账来源的重复数值奖励被拦截。房主存档保存共享来源和永久进度，随正常游戏保存写入磁盘。

## 进度共享关闭时

- 普通怪、机关、奖励、剧情和存档由本机原生运行；完整存档同步同时停用。队友刀光和法术不能伤到本机的私人普通怪或触发私人机关。
- 保留匹配的同房 Boss 合作及队友位置。传送和暗影救援继续遵从原有独立开关。
- 在实体构造前统一过滤，只允许 Boss、登记的战斗必需对象及有真实 Boss 来源的生成物进入同步。挡板和镜头锁区继续走本地触发；不同进度的场景保留本地布局。
- 修复没有对应远端 Boss 时，本地原对象恢复后仍停用的问题；修复大黄蜂独立的针被当作普通危险物过滤，重连后卡在投针等待的问题。

## 设置与此前修复

模组菜单现在提供「队友透明度（本机）」「队友名字配色（本机）」「动态 Boss 血量（房主）」。默认依次为关闭（不透明）、开启、关闭；前两项各调各的，第三项使用房主开房时的规则。菜单与配置说明见[设置入口](DISPLAY-MENU-2026-10-20.md)。

保留战斗挡板和镜头锁区本地化、粪球守卫者剧情标记补齐、苍绿之径藤蔓石块本地化，以及此前的精英战结算、动态 Boss 难度、辐光平台、击败 Boss 后解除暗影和紧急回椅修复。普通地图的永久机关在共享模式下仍遵从原有同步范围。

## 本轮检测

检测在升为 0.1.27 后构建的最终 DLL 上进行，逐组核对主客端完成标记、严格日志和生产哈希。相关核心 **38 项通过、0 失败**，构建无警告、无错误；**8 组双端检查全部通过**。具体结果与哈希记录于[打包与运行证据](evidence/runtime-room-0.1.27.json)。旧版本、旧哈希的通过记录保留原范围，不追认为本版完整认证。

通过范围：双端共享入队与原生领取、本地世界隔离及切回共享、不同 Boss 进度、大黄蜂六轮投针重连；追加真菌荒地双蘑菇精英战的打完后迟入、同房晚触发两种情况，交换房主/客机先入，共四组。精英房 8 个端次均实际走过左右门、完成原生领奖并恢复控制，护符槽只增加一次；本轮未复现这四种时序中的出不去、无奖励问题。共享入队组也通过了旧档已标记领取却缺失护符槽的补差检查。使用同机隔离游戏副本和真实 localhost UDP，不修改个人存档。Boss 和精英怪终结伤害由部分探针注入，不代表完整人工战斗验收。

## 已知边界

没有执行全游戏或全部 Boss 矩阵，也没有执行双机 FRP 验收。[历史问题记录](evidence/runtime-blockers-0.1.27.json)继续保留，包括旧例中的镜头冻结、罕见接管失败、地图购买后队友不可见等未解项。本轮单个专项通过不会自动关闭这些历史记录。

剧情灵魂大师在此前双端诊断中，存在未入场队友在房主完成后仍被挡板挡住的问题；共享开/关对照均有失败，当前未关闭，详见[诊断记录](SOUL-MASTER-VERIFICATION-2026-10-20.md)。本包继续明确标注该限制，不把诊断流程完成当作功能通过。

## 安装

完整解压 Windows 包，关闭游戏后运行 **一键安装.exe**，选择游戏并点击 **安装 / 更新**。源码包用于开发。更新后所有玩家重新开房；紧急回椅为 **Ctrl+Alt+F12**，诊断面板为 **F9**。
