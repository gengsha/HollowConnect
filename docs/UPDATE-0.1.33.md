# HollowConnect 0.1.33

2026-10-23。沿用测试渠道，`releaseReady=false`。引擎为 **HKMP 3.0.0-hc13**，联机标识为 **0.1.33-l6**。房主和所有队友更新同一个完整包并重新开房；已有存档与配置保留。

## 相对 0.1.32 的变化

- **队友动作反馈隔离。** 远端特效不再触发或停止本机手柄振动；远端挥刀碰墙不再让本机角色后坐力移动。本机原生振动与挥刀反馈保留。
- **马科斯梦之盾。** 清理非权威 Boss 在入场权威确定前生成的游离盾，避免出现额外环绕的盾。
- **佐特字幕。** 字幕对象保留原生展示及淡出流程，修饰词和名字在同房间正常消失。
- **叛徒领主及乌姆 Intro 镜头。** 放行原生镜头锁自停用事件，保留正常战斗镜头边界。
- **乌姆小水母。** 同步原生水母波次、尸体和核心出生；核心按击破者确定追踪目标，客机跟随权威运动。
- **动态 Boss 伤害占比榜。** 房主菜单开关，默认关闭。普通流程／单体挑战按每场统计；神居一至五门跨 Boss、休息房累计，原生终场完成后结算。Alt+A 本地隐藏／显示，隐藏时继续统计。轻透窄面板复用原生中文字体、数字字体和花饰。
- **菜单说明重叠。** 说明放到列表下方固定区域，一次只显示当前选项；名称和值分栏，长文字适配字号。锁定说明保留，返回或关闭时清空。

## 本轮验证范围

按用户要求执行必要的定向验证：16 项相关核心检查、一组原生菜单专项，以及六组双端检查（反馈隔离、马科斯／佐特／叛徒领主、乌姆、伤害榜前两房累计、第二门修奥终场结算、房主关闭伤害榜）。最终结果及实际生产哈希见 [验证记录](evidence/runtime-room-0.1.33.json)，包内 DLL 与运行记录绑定。

前两房检查使用完整原生序列，验证真实扣血、双方来源归属、远端脱离角色法术、隐藏继续统计和原生换房后的累计，再在明确边界停止；没有缩短原生序列或强制原生 Boss FSM 通过。终场另用完整第二门序列上下文直接进入修奥场景，验证其原生最终完成回调。

菜单检查覆盖所有项的未锁定／锁定说明、文字完整可见、说明与滚动列表分离、名称／值列分离、快速选择及返回／关闭清理。游戏检查使用既有隔离副本和临时内存数据，保存及全局配置写入被拦截。

本轮未重跑完整房间矩阵、完整连续五门、三至五门逐门通关、每个 Boss 所有流程／阶段或真实跨机器 FRP；手柄检查记录原生振动入口，未连接实体手柄测量马达。历史未解问题继续保留，详见 [已知问题](evidence/runtime-blockers-0.1.33.json)。第一门奥罗的原生终场在先前定向检查停于 Death Air，原因未确认，未纳入通过范围。本版不声称该问题已修复。

此前开发证据和修复细节见 [反馈隔离](REMOTE-FEEDBACK-FIX-2026-10-23.md)、[四项 Boss 修复](P5-FOUR-FIX-2026-10-23.md)和[伤害榜](BOSS-DAMAGE-RANKING-2026-10-23.md)。旧哈希通过记录保留为历史证据。

## 安装

关闭游戏，完整解压 **HollowConnect-0.1.33-windows.zip**，运行 **一键安装.exe → 安装 / 更新**。所有玩家更新同一包并重新开房，无须先卸载或新建存档。FRP 端口配置沿用原设置。
