# HollowConnect 0.2.2

2026-10-28。Windows 完整安装包与源码包，GitHub 正式 Release，网络标识 `0.2.2-l8`，引擎为 `3.0.0-hc13`。房主和队友更新为同一完整包后重新开房。

## 本次更新

- 修复五门分头推进后，旧休息房进度覆盖新进度、出口重复进入上一段的问题；坐椅子或对话中的等待者也能更新出口。
- 幼虫按 46 个独立来源共享；收藏家房间三只分别记录，避免重复发奖，并正确更新地图标记。
- 城市纹章、典雅的钥匙、爱之钥、店主的钥匙采用简单钥匙的来源共享逻辑，各自消费，重连不补回已使用的钥匙。
- 七位梦战士和五位梦境 Boss 的首次精华奖励按来源共享；本机随后领取和重复回执不重复加点。梦之树点数继续个人获得。
- 所有按来源共享的资源使用左下角信息提示；钥匙显示具体名称，梦境精华显示数量。
- 动态 Boss 血量新增可输入的单参数，默认 `60`，范围 `0–400`。填 `80` 时，两人血量为 `180%`、三人为 `244%`；开房后按房主参数锁定。
- 修复分头解锁鹿角虫车站后，站点计数未合并、无法通过原生对话解锁巢穴的问题。
- 修复玩家重进后伤害榜出现两行相同名字，重连后继续累计到原行。

## 下载与安装

- `HollowConnect-0.2.2-windows.zip`：游玩用完整包，含一键安装器及依赖。
- `HollowConnect-0.2.2-source.zip`：对应源码，供开发使用。
- `SHA256SUMS-0.2.2.txt`：两份压缩包的 SHA-256 校验值。

完整解压 Windows 包，关闭游戏后运行 **一键安装.exe**，选择游戏并安装／更新。安装器沿用现有备份流程。
