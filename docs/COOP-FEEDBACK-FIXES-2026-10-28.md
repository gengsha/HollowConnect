# 联机反馈修复（2026-10-28）

本次针对五门休息房倒退、幼虫收集、鹿角虫巢穴和伤害榜重连重复。没有升版或打包。

后续交付：上述修改已纳入 [0.2.2](UPDATE-0.2.2.md)。本页保留此前实机记录及其原始哈希。

同日后续的可输入 Boss 血量参数、梦境精华、钥匙共享和左下角提示见 [追加修改](HEALTH-ESSENCE-KEYS-2026-10-28.md)。本页的实机记录只对应本页列出的受测哈希。

- **五门休息房：** 同一轮连战的多个休息点复用 `GG_Spa`。旧休息房中的场景权威可能持续发送旧段数，覆盖独自推进后回来的队友。现在同场景、同连战和约束条件下只采纳较新的休息段数，并由原生配置更新出口。坐椅子或对话中的等待者也能更新出口，保持原有操作锁定。服务器仅在同房成员段数不一致时附带推进者上下文，检查等待者已实际进入该房间，不改变普通 Boss 战和权威选举。
- **幼虫：** 使用现有共享来源回执，登记 46 个独立来源。普通瓶子按场景和原生 ID 识别；收藏家房间三只瓶子共用原生持久 ID，改以固定位置次序区分。重放、重连和本机重复收集同一来源不重复加数，远端收集有左下角提示。本机仍可完成原生打瓶动画。收藏家房间三条记录齐全后才完成该场景的地图标记；幼虫奖励领取进度不由本修复合并。
- **鹿角虫巢穴：** 根据九个原有站点的解锁并集补齐原生 `stationsOpened`，使分头买站点的队伍也能触发鹿角虫的第三段回忆对话。巢穴仍由原生对话解锁，隐藏车站不成为额外前置条件。
- **伤害榜：** 同一张榜按服务器不区分大小写的玩家名保留累计行，连接 ID 只用于当前连接的伤害归属。离线后清理旧连接的报告和场景索引，重进继续累计到原行。

旧档的幼虫来源只从确定的原生记录导入：普通瓶子的持久记录，或已完成整间房收集的 `scenesGrubRescued`。不从一个不明来源的总数反推部分收集位置，也不猜测收藏家房间尚未完整保存的部分来源。
