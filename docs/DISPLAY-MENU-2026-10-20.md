# 显示与 Boss 难度菜单补全（2026-10-20）

交付追记：本项随 [0.1.27](UPDATE-0.1.27.md) 打包；下文保留实施时版本与受测哈希，不追认为新版全部二进制的实机认证。

此前 0.1.26 包只有 JSON 配置入口，HollowConnect 菜单漏了透明度和 Boss 难度，也没有名字配色开关。本次补全菜单；未升版、未打包，不修改个人配置或存档。

入口：游戏「选项 → 模组 → HollowConnect」。

| 菜单项 | 默认 | 作用与生效时机 |
|---|---|---|
| 队友透明度（本机） | 关闭（不透明） | 可选 75%、50%、25% 不透明和完全透明；本机立即生效，包含队友身体和特效，自己与名字不受影响 |
| 队友名字配色（本机） | 开启 | 队友头顶名字沿用地图/方位颜色，自己白色；关闭后头顶名字白色，本机立即生效 |
| 动态 Boss 血量（房主） | 关闭 | 房主开房前选择，改动后重新开房；访客自己的值不能改变房间规则 |

本机显示选项不发送同步包。Boss 使用现有房主规则和伤害折算机制，此次没有改动 Boss 伤害、阶段或网络协议。

JSON 保留 `OtherPlayerOpacity`（默认 1）与 `BossHealthScaling`（默认 false），增加 `ColoredPlayerNames`（默认 true）；旧配置缺少新字段时自动采用 true。已有自定义透明度原值保留并显示在菜单中，打开菜单不会取整覆盖。既有显式配置不因默认值变化而重置。

为支持从默认不透明即时切换，远端身体/特效在原创建入口登记渲染组件；不透明时关闭其逐帧着色脚本，设置变化时只刷新登记对象和已存在的玩家名字，不扫描整个场景，不修改共享材质或队伍/碰撞规则。透明度关闭时恢复原色，防止留在不可见状态。

## 验证

生产与 Smoke 编译通过；`tests/boss-balance.selection.txt` 的 4 项核心检查通过。

定向实机目录：`.test-results/display-menu-20261020-a`，同机双 Unity、真实 localhost UDP，隔离游戏副本，内存角色 99，存档写入拦截。房主/访客分别通过 23/25 项断言（单一场景内的检查数，并非独立用例数），双方正常断线停服、产生 done，停止隔离进程后严格日志检查通过。

本轮验证旧 JSON 缺字段默认值、菜单三项默认值、自定义 45% 不透明值不会被打开菜单覆盖、默认不透明时没有逐帧着色、房主启用/访客关闭时以房主为准、当前会话不受后续菜单难度修改影响、两端透明度与名字开关互不影响、已有角色即时切换、完全透明及关闭后的身体和脱离角色的暗影之魂恢复、本人保持不透明/白名、配置内存序列化往返。没有写入个人配置或存档；没有重新进入 Boss 战斗，没有重跑历史进度或战斗矩阵，也没有做真实双机网络验证。
